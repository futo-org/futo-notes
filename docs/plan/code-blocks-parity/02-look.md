# 2. Look

!300's spec states nothing about a block inside a list item or a quote, and gives no light/dark rule beyond the light-theme selection measurements and the dark-theme contrast figure below. The only font-size rule is that the header corner scales with the font (desktop). The engine reads an indented opening fence under a bullet, and reads no fence after `>` (ld 151-152). Android's header scales with the system font size (fc 12). On wrapping, !300 states only that a soft-wrapped code line's selection paints per visual row (cb 419-420, 540-543). It does not state whether long code lines wrap or scroll. For an unclosed block, see section 1 (cb 911-915). For an empty block, see the last row of this section.
