# Demo notes for the code-block parity checks

The notes the verifiers seeded on both emulators (ours and the !300 reference) at S23 size. Each is one case:
`Code blocks demo` is the full tour, `Touching demo` has blocks with no line between them, `Lines demo` and
`Lines B demo` have line marks in their fences, `Low demo` puts a block at the bottom of the screen for the keyboard
checks. `Editor demo` (with `demo-image.png`) is the table and image note. Seed them into a debug vault's notes
folder; the area sections of VERDICT.md name the note each check used.
