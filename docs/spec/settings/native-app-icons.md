## Native app icons

- _(native shells)_ An **App icon** section directly after Appearance shows the current icon thumbnail and localized name; tapping opens a native picker sheet. → apps/ios/Sources/Settings/AppIcon/, apps/android/app/src/main/java/com/futo/notes/ui/settings/appicon/
- _(native shells)_ The six permanent choices are **Standard**, **Reversed**, **Dark**, **Dark, Reversed**, **FUTO**, and **Scanlines** (the orange gradient, stripes, and white mole); the choice belongs to this installation and is independent of theme and sync.
- _(native shells)_ Selecting a different choice requests an OS change, disables further choices while pending, and marks the actual OS selection only after readback; selecting the current choice is a no-op. The sheet stays open unless the OS closes the app (Android).
- _(Android)_ A change first asks `Change app icon to "<name>"?` with **Change** / **Cancel**; Cancel changes nothing. The body says FUTO Notes may close: disabling the launcher alias that started the task makes Android finish that task, while a task started another way survives.
- _(Android)_ Full reset requests Standard without this prompt; the reset confirmation already covered it.
- _(native shells)_ A failed request retains the actual icon and shows a localized error; dismissing the sheet does not undo a completed change.
- _(iOS)_ Icon choices show the artwork, name, and selection checkmark without container boxes, on a theme-aware surface background (light gray in light mode).
- _(iOS)_ The picker shows no spinner or changing-icon status text while a request is pending; the Scanlines artwork has no outer outline.
- _(iOS)_ The OS alternate-icon name is authoritative; the default uses nil, unsupported devices show the current preview and an unavailable message, and Apple's icon-change notification remains enabled.
- _(Android)_ PackageManager alias state is authoritative; API 33+ changes all aliases in one atomic batch with DONT_KILL_APP, older APIs enable the requested alias before disabling others and attempt to restore the prior icon after failure.
- _(Android)_ Startup and picker observation reconcile an interrupted transition with multiple enabled aliases while preserving a valid single selection; MainActivity remains enabled for editor lifecycle, and LicenseLinkActivity keeps receiving license links.
- _(Android)_ Launcher refresh may lag the request; system themed icons may recolor the artwork and suppress color/texture differences.
- _(native shells)_ After a confirmed full reset wipes the vault and preferences, request Standard; an icon-reset failure is reported separately because the notes have already been reset, preserving stop-sync-before-wipe ordering.
- _(native shells)_ **Unlicensed or Expired** (the license does not include the app icon): every tile except the current one wears a coin badge; tiles are not dimmed or disabled. One footnote under the grid, `settings.appIcon.license.footnote` ("unlocks"), or `settings.appIcon.license.footnoteKeyOnly` ("included with") when the sheet is key-only; same `license_row_actions` rule. Tapping the current tile is a no-op. → `AppIconPicker.swift`, `AppIconPickerShape.kt`
- _(native shells)_ Tapping a badged tile opens a sheet (not the OS icon change): the tapped icon's artwork with the coin badge, the title `settings.appIcon.license.sheetTitle`, one paragraph, one filled button, text links. The shape follows `license_row_actions`: if it contains Buy or Renew the sheet is **link-out**, otherwise **key-only**; no storefront logic of its own.
- _(native shells)_ Link-out sheet: paragraph `settings.appIcon.license.sheetBody`; filled **Buy a license** (`license.buy`, or `license.renew` when Expired) opens the Buy URL with `from=app-icon` the way the License card does (default browser on iOS, Custom Tab on Android); **I already paid** (`license.enterKey`) dismisses the sheet and the picker, scrolls Settings to the License card and opens its key field; **Not now** (`settings.appIcon.license.notNow`) returns to the grid.
- _(native shells)_ Key-only sheet (ADR-0005): paragraph `license.keyOnlyExplanation`, filled **I already paid**, link **Not now**. No Buy, no "Lost your key?", no website, no other copy.
- _(iOS)_ When the App Store product loaded (license.md § App Store purchase), both sheets also offer **Buy in App Store** (`license.appStore.buy`): on the link-out sheet as the License card's captioned pair beside Buy (`LicenseBuyPair`), with a full-width quiet **Not now** under it and **I already paid** as a text button below that; outlined under **I already paid** with `license.appStore.scope` on the key-only sheet. The sheet then sizes to its content. A completed purchase drops the sheet and the picker gains the landing header with `settings.appIcon.license.landingAppStore`. → `AppIconPicker.swift`, `AppStorePurchaseTests`
- _(iOS)_ An owned App Store purchase includes the icons exactly as a Licensed key does: the picker, row hint and footnote read Licensed (Rust's `license_evidence_includes`). A refund returns the ask; the icon already set stays.
- _(native shells)_ The App icon row shows a trailing coin and `settings.appIcon.license.rowHint` before the chevron while the license does not include icons, on key-only builds too (the hint names a fact, not a sale). The License card gains no sentence.
- _(native shells)_ While the license has not been read yet (launch, first moments), the row hint, coins and footnote are absent and a tap on a tile does nothing: unknown is neither licensed nor unlicensed, so no ask appears until the state is resolved.
- _(native shells)_ The ask sheet drops itself only when the license now includes the icon; foregrounding the app (including returning from the browser after Buy) leaves it open.
- _(native shells)_ **Licensed:** the footnote, sheet and row hint are gone; the coin stays on every tile except Standard (the current one included), so the picker still shows which icons came with the license. Tapping a tile changes the icon exactly as before.
- _(native shells)_ The gate is on choosing, never on keeping: a removed or expired license leaves the icon set as it is, and the only automatic change is Full reset's Standard. Expired renders as Unlicensed with Renew where Buy would be.
- _(native shells)_ A coined tile's accessibility label is `settings.appIcon.license.a11yIncluded` ("{iconName}, included with a license"); the sheet's title is its heading.
- _(native shells)_ Right after a successful activation the picker opens over Settings with a one-time header (coin, `license.explanationLicensed` in bold, `settings.appIcon.license.landing`); see license.md § Deep link. Skipped when the OS cannot change icons (iOS only; Android always can).
- _(Android)_ The ask is a second ModalBottomSheet over the picker. `direct` builds get the link-out ask and footnote. `play` builds name the website instead: footnote `settings.appIcon.license.footnoteWebsite`, sheet paragraph `settings.appIcon.license.sheetBodyWebsite` with the storefront address as plain, non-tappable text, filled **I already paid** and **Not now**; no Buy and no "unlocks" (license.md § What a license includes). The "Change app icon to …?" confirm still guards the change once the license includes it. → `AppIconSheet.kt`, `AppIconSheetTest`, `AppIconLandingTest`
