## Editor exits — every way an open note ends _(mobile)_

- An open note is owned by a Rust editor session. The native view reports input and applies returned revisions, selections and identity changes; document bytes never come from JavaScript. → crates/futo-notes-ffi/src/editor/, docs/architecture/text-first-editor-host.md
- Navigation settles pending title and image work and checkpoints the session against its current identity, so a stale completion cannot recreate a renamed or deleted note. → apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstEditorScreen.kt, apps/ios/Sources/Editor/TextFirst/TextFirstLeaves.swift
- A failed save retains the dirty session and its attachment for retry or an explicit discard; leaving a screen never silently drops its unsaved draft. → apps/ios/Sources/Editor/TextFirst/TextFirstLeaves.swift, apps/android/app/src/main/java/com/futo/notes/textfirst/EditorEngineStorage.kt
- *(iOS)* System Back and the edge swipe may pop before saving finishes. The leave registry owns the controller until saving is durable, or hands it back when the note is reopened. → apps/ios/Sources/Editor/TextFirst/TextFirstLeaves.swift, apps/ios/Tests/Editor/TextFirst/TextFirstLeaveTests.swift
- *(Android)* The registered leave handler completes the native close workflow before invoking pending navigation; failure keeps the editor and its save error available. → apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstEditorScreen.kt
- An untouched, empty quick-capture note is discarded on leaving. Opening and closing an unchanged existing note preserves its exact bytes, including whether it ends in a newline. → docs/spec/list.md, docs/spec/editor/portable-core/recovery.md
- Backgrounding requests a native checkpoint. Failed saves remain owned and retryable. → apps/ios/Sources/Editor/TextFirst/TextFirstNoteScreen.swift, apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstController.kt
- Native debug inspection reads the Rust-backed renderer and uses platform input. Release apps carry no web editor or JavaScript inspection bridge. → apps/ios/Sources/App/PuppetNative/, apps/android/app/src/debug/java/com/futo/notes/puppet/PuppetNativeEditorState.kt

Saving, merge dispositions and source ownership follow [the portable recovery contract](portable-core/recovery.md). Native leave, identity, composition and checkpoint suites exercise these workflows through real sessions.
