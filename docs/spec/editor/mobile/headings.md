# Heading keys

- *(mobile)* Backspace at a heading's visible start removes the blank line above and retains the heading, or joins its text onto the end of the text, heading or list line above, dropping the heading's marker. A first-line heading, or one under a divider, table or front matter, becomes Text instead; one immediately after a fenced code block lands its shown text on the code's last line as code (a link or mark keeps only its text; an empty block gains the line) and the heading line goes.
