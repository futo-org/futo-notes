# Tables

- *(mobile)* The native text-first editor renders existing root tables as a header/body grid (160 pt columns, borders, the header row filled and semibold, the delimiter line shown as nothing, each column's alignment kept) with one shared horizontal scroll per table; a horizontal drag that starts on a table scrolls all its columns together and any other drag scrolls the note. The row's Markdown spelling stays in the text, hidden, and the caret never stops inside a row. Tapping a cell raises no keyboard on the note; it selects that cell's content and opens a cell-sized field in place over the cell (not a sheet or separate screen), on the same editor session. Typing, deleting, composition, single-cell paste, copy, cut, Enter (the cell below), Tab and Shift+Tab (hardware keyboard) and Undo in the field are the engine's, in the note's own display coordinates, so a typed `|` lands as typed and starts a new cell, while a pasted `|` is written `\|` and a pasted line break becomes a space; Done, or a tap on the note outside the field, returns to the note. Image content is refused while the selection is in a cell: no file is written. Existing alignment and untouched bytes survive save and reopen.
