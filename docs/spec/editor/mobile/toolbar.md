# Toolbar state and commands

- *(mobile)* Bold, Italic and Strikethrough light only when every selected visible character other than whitespace carries that format, across lines and blocks alike, so a lit button means a tap removes it; a collapsed caret shows its carried formats. Code block and the list buttons follow the line the selection starts on, and Heading and Quote follow their taps' rule (markdown-toolbar/toolbar-commands.md); Text lights when none of those does, and a level 4–6 heading, which has no control, lights none. → crates/futo-notes-editor/src/engine/surface.rs `toolbar`, crates/futo-notes-editor/src/engine/commands/inline/mod.rs `toolbar_formats`, crates/futo-notes-editor/src/host/toolbar_ids.rs, crates/futo-notes-editor/tests/host_toolbar_ids.rs, apps/android/app/src/main/java/com/futo/notes/textfirst/EditorEngineCaret.kt, apps/ios/Sources/Editor/TextFirst/TextFirstEditorController+Toolbar.swift, apps/ios/Tests/Editor/TextFirst/TextFirstToolbarStyleTests.swift
- *(mobile)* Inline formats and Link are dimmed when the engine disallows inline formatting; Indent, Outdent, Undo and Redo are dimmed when their canonical eligibility or history query says they cannot run. These controls stay visible. → crates/futo-notes-editor/src/engine/surface.rs `toolbar`, apps/android/app/src/main/java/com/futo/notes/textfirst/EditorEngineCaret.kt, apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstToolbar.kt, apps/ios/Sources/Editor/TextFirst/TextFirstEditorController+Toolbar.swift, apps/ios/Tests/Editor/TextFirst/TextFirstToolbarStyleTests.swift
- *(mobile)* The toolbar offers H1, H2 and H3 without a separate Text control; choosing the common active heading level again returns the selected headings to paragraphs, retaining enclosing quote depth. → apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstToolbar.kt, crates/futo-notes-editor/src/engine/commands/blocks/mod.rs `block_toggle`, crates/futo-notes-editor/tests/fixtures/engine/blocks.json, apps/ios/Sources/Editor/TextFirst/TextFirstEditorController+Toolbar.swift, apps/ios/Tests/Editor/TextFirst/TextFirstToolbarStyleTests.swift

- *(iOS)* The native editor extends through the bottom container safe area while respecting the keyboard; its background is continuous with the rest of the note screen. Code backgrounds and quote bars meet at pixel-aligned edges without translucent overlap bands between physical lines. → apps/ios/Sources/Editor/TextFirst/TextFirstNoteScreen.swift, TextFirstLayoutFragments.swift
