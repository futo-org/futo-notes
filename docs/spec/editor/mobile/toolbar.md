# Toolbar state and commands

- *(mobile)* Bold, Italic and Strikethrough light only when the selection carries that format — within one block the whole selection, across blocks every selected inline body (edge whitespace and blank lines aside), so a lit button means a tap removes it; a collapsed caret shows its carried formats. Block controls light only for the common selected block kind, with mixed blocks left unlit. → crates/futo-notes-editor/src/session/toolbar.rs, crates/futo-notes-editor/src/session/formatting.rs `selected_toggle_formats`, apps/android/app/src/main/java/com/futo/notes/textfirst/EditorEngineCaret.kt, apps/ios/Sources/Editor/TextFirst/TextFirstEditorController+Toolbar.swift, apps/ios/Tests/Editor/TextFirst/TextFirstToolbarStyleTests.swift
- *(mobile)* Inline formats and Link are dimmed when the engine disallows inline formatting; Indent, Outdent, Undo and Redo are dimmed when their canonical eligibility or history query says they cannot run. These controls stay visible. → crates/futo-notes-editor/src/session/toolbar.rs, apps/android/app/src/main/java/com/futo/notes/textfirst/EditorEngineCaret.kt, apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstToolbar.kt, apps/ios/Sources/Editor/TextFirst/TextFirstEditorController+Toolbar.swift, apps/ios/Tests/Editor/TextFirst/TextFirstToolbarStyleTests.swift
- *(mobile)* The toolbar offers H1, H2 and H3 without a separate Text control; choosing the common active heading level again returns the selected headings to paragraphs, retaining enclosing quote depth. → apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstToolbar.kt, crates/futo-notes-editor/src/session/blocks/commands.rs, crates/futo-notes-editor/tests/blocks/toggle.rs, apps/ios/Sources/Editor/TextFirst/TextFirstEditorController+Toolbar.swift, apps/ios/Tests/Editor/TextFirst/TextFirstToolbarStyleTests.swift
