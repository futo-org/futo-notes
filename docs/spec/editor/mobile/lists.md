# Lists, checkboxes and links

- *(Android)* A list item beginning with fenced code paints its engine-supplied marker on the first visible code line; hidden fence rows add no extra list or quote margins, and continuation lines remain unmarked. → apps/android/app/src/main/java/com/futo/notes/textfirst/SpanPlan.kt `planSpans`, apps/android/app/src/test/java/com/futo/notes/textfirst/RenderWorkTest.kt
- *(mobile)* Selecting a complete list row extends its highlight over the rendered number, bullet or task checkbox; a caret or partial-word selection does not highlight that marker. → apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstEditTextSelection.kt `drawListSelection`, apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstSpans.kt `drawSelectedMargin`, apps/android/app/src/androidTest/java/com/futo/notes/textfirst/TextFirstCaretTest.kt `listMarkersFollowNativeSelectionWithoutATextChange`, apps/ios/Sources/Editor/TextFirst/TextFirstLayoutFragments.swift `highlightedMarkerRect`, apps/ios/Tests/Editor/TextFirst/TextFirstBlockDrawingTests.swift `aFullySelectedRowHighlightsItsMarker`
- *(mobile)* A tap on a task's checkbox, on an external link's own glyphs or on a resolved wikilink acts on that control alone: the checkbox toggles, the link opens, the note opens, and the tap places no caret and raises no keyboard (the caret stays where it was). A tap on the text beside them is ordinary text interaction. → apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstEditText.kt, apps/ios/Sources/Editor/TextFirst/TextFirstEditorController+Taps.swift, apps/ios/Sources/Editor/TextFirst/TextFirstEditorController+Links.swift, apps/ios/Tests/Editor/TextFirst/TextFirstLinkTests.swift
