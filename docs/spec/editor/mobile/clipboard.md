# Clipboard and system text actions

- *(mobile)* System text actions other than the clipboard (Look Up, Translate and other process-text apps, Share, smart text classification, the keyboard's view of the selection) receive the selection's visible display text without Markdown markers; Copy and Cut alone export Markdown. The view holds display text only, and only the clipboard actions, undo and redo are routed to the engine. Verified on iOS by a unit test; Android is code-verified. → apps/android/app/src/main/java/com/futo/notes/textfirst/TextFirstClipboard.kt, apps/android/app/src/main/java/com/futo/notes/textfirst/DisplayMirror.kt, apps/ios/Sources/Editor/TextFirst/TextFirstTextView.swift, apps/ios/Tests/Editor/TextFirst/TextFirstEditorTests.swift `systemTextActionsSeeDisplayTextWhileCopyAndCutExportMarkdown`
