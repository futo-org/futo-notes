# Tables: cells, keys, rows and columns

These are the portable replacement core's contracts. The shipping Milkdown editor keeps
its interaction contract until renderer integration (`../interactive-elements.md`,
`../markdown-house-style.md` "Tables"). Views never spell pipes or the delimiter row.
What is a table is the dialect's rule (`linedown.md`, "Tables"): a `|` header line, a
delimiter row directly under it, then every following `|` line, at the top level only.

- A table is read from the line readings: its header, delimiter row and rows. Each line's cells are read from that line alone; unescaped `|` bounds cells and `\|` is text in its cell. Alignment comes from the delimiter row's cells (`:--` left, `:-:` centre, `--:` right). → crates/futo-notes-editor/src/engine/commands/tables/mod.rs
- A table is as wide as its widest row. A row with fewer cells lists only the cells it has and is drawn padded; a cell past the header is a column like any other, and its text is edited and formatted like any cell's (#419). → crates/futo-notes-editor/src/engine/commands/tables/mod.rs, crates/futo-notes-editor/tests/fixtures/engine/tables.json
- Table inspection projects cells in the note's own display coordinates, so one selection serves the note and the cell view. A cell's content excludes its edge spaces and tabs; an empty cell's content is the point after its first padding space. The focused cell is the one a range lies wholly inside, on a header or body line; a range on the delimiter row or outside every cell finds the table with no focus. `inspect_tables` lists every table a line of the range lies in, each once. Each row's line and the delimiter row are reported as display ranges for hosts that lay out one line per row. → crates/futo-notes-editor/src/engine/commands/tables/mod.rs
- The commands that apply to the focused cell are plain state: the header row cannot be deleted or have a row inserted above it, the last body row cannot be deleted, and a one-column table cannot lose its column. A disabled command changes nothing. → crates/futo-notes-editor/src/engine/commands/tables/mod.rs
- Typing in a cell lands as typed, like typing anywhere: a typed `|` starts a new cell in that row, and a typed line break breaks the row's line, which ends the table there unless the new line starts with `|`. Nothing is escaped because of what is typed. Text a text service or dictation inserts inside one cell, marked text an input method commits included, has its line breaks turned into spaces as a paste's are (edge line breaks dropped); its other characters, a `|` included, land as given. → crates/futo-notes-editor/tests/fixtures/engine/tables.json, crates/futo-notes-editor/src/engine/commands/tables/mod.rs `cell_service_text`
- Tab and Shift+Tab select the next/previous cell's content, row by row (Tab in the last cell appends a row and enters its first cell; Shift+Tab in the first cell is left to the host). Enter selects the content of the cell below, and on the last row appends a row and enters the same column. Shift+Enter is Enter: a cell holds one line. A move is a selection change with no edit and no history. → crates/futo-notes-editor/src/engine/commands/tables/keys.rs
- Entering a cell a row lacks gives that row empty cells up to it, in one edit; a last cell with no closing pipe is closed first, its bytes untouched. A header that gains cells gives its delimiter row the same count (` --- ` cells), so the two still agree. → crates/futo-notes-editor/src/engine/commands/tables/keys.rs
- Mod+Enter puts the caret on an empty line after the table: it moves to the line after the table when that line is empty, and otherwise writes one line ending after the table's last line. → crates/futo-notes-editor/src/engine/commands/tables/keys.rs
- Paragraph Enter, Shift+Enter, Tab and Shift+Tab with the range inside one cell are the table's keys, ahead of every other family. A paragraph key on a table line outside every cell (before a row's first pipe, past its last) is not the table's: Enter there writes a line break, which ends the table at that line. → crates/futo-notes-editor/src/engine/commands/tables/keys.rs
- Backspace or Delete at a collapsed caret never removes a pipe that bounds a cell (the leading pipe and the delimiter row's pipes included) or the line break between two lines of one table: the caret stays and nothing is written. Every other deletion in a table, an escaped pipe's included, deletes as it does anywhere. → crates/futo-notes-editor/src/engine/commands/tables/keys.rs
- Row and column insertion and deletion edit table lines only, name every line they change, and insert or remove whole cells at their pipes, so every untouched cell, the alignment markers and a missing final line ending keep their exact bytes. A new row is `|` then `  |` per column, in its neighbor's line ending; a row inserted below the header goes below the delimiter row, and a header-only table gains its first body row. A new column is an empty `  ` cell (` --- ` in the delimiter row) on every line that has a cell at that position or ends right before it as one of the widest rows; a shorter row stays padded. Deleting a column removes the cell and the pipe after it (for a row's last cell, the pipe before it; a last cell with no closing pipe goes alone); a line's only cell is emptied instead, and a delimiter row keeps its only cell. A command is one accepted edit and one undo step. Alignment changes, row and column reordering and multi-cell or grid paste are deferred. → crates/futo-notes-editor/src/engine/commands/tables/structure.rs
- A row or column command keeps a caret or selection in the focused cell when the cell survives; after deleting the focused row the caret goes to the start of the cell below (above, for the last row), and after deleting the focused column to the cell to its right (left, for the last column). → crates/futo-notes-editor/src/engine/commands/tables/structure.rs
- Plain-text paste inside one cell drops edge blank lines, turns every other run of whitespace holding a line break into one space, keeps edge spaces and tabs, and writes a pasted `|` as `\|`, so it never reaches another cell; a paste that would still change the row's cells is refused with `UnrepresentableFormat`. A range across cells, or from a table line out of the table, is refused with `UnrepresentableFormat` (a valid range is never answered `InvalidRange`, #355); a caret on a table line outside its cells, and a range outside every table, is ordinary paste. The clipboard family calls the cell path first. → crates/futo-notes-editor/src/engine/commands/tables/paste.rs, crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs
- A link command (`set_link`, `edit_link`) never damages a table: a link stays inside one cell. A range inside one cell links it there; a selection across cells or rows, or from a line into a cell, links each cell it covers (and each line) in one accepted edit and one Undo step, as the inline format toggles do, and unlinking it removes each link whose text it touches; the pipes and the delimiter row take none. A label edit across cells or out of the table, and a caret on a table line outside every cell (before a row's first pipe, past its last, on the delimiter row), change nothing: no edit, no history. A cell's link is kept only when the row reads back with the same cells, so a destination holding `|` is refused (`UnrepresentableFormat`). A `|` line with no delimiter row under it is a plain line and is linked whole. → crates/futo-notes-editor/src/engine/commands/inline/links/mod.rs `link_command`, crates/futo-notes-editor/src/engine/commands/tables/mod.rs `outside_one_cell`, crates/futo-notes-editor/tests/fixtures/engine/inline.json, crates/futo-notes-editor/tests/links/tables.rs
- A table needs no staging at any size: a key in a cell re-reads its own line, so typing and Backspace in a middle cell cost the same counted work at 20,000 rows as at 100 (about 300). Navigation, inspection and row and column commands read the whole table, since its width is its widest row; a column command also writes every row. In a 20,000-row table of URL cells (1.9 MB) on a desktop release build, Tab takes about 4 ms, inspection 12 ms, a row insert about 1.9 M counted work and a column insert 11.5 M and 46 ms. → crates/futo-notes-editor/src/engine/tests/tables.rs
- Portable, Store and native layers expose the same operations behind the usual acceptance and acceptance barrier; each step restores exact bytes. → crates/futo-notes-editor/src/portable/tables.rs, crates/futo-notes-store/src/editor_session/tables.rs, crates/futo-notes-ffi/src/editor/tables.rs
