# Heading, quote and divider block commands

- *(Android native text-first editor)* Empty editable lines have the same height as ordinary text lines, including between a quote and the next paragraph; typing on an empty line does not expand the gap. → apps/android/app/src/main/java/com/futo/notes/textfirst/SpanPlan.kt

- *(Android native text-first editor)* Block styling remains visible while the keyboard composes a word, including the first character on an empty quote, heading or code line; a quote's margin does not extend into the following plain line. → apps/android/app/src/androidTest/java/com/futo/notes/textfirst/TextFirstBlockIndicatorTest.kt
- ATX heading levels one through six, setext headings, nested quotes and dividers project without their source markers; revision-tagged block descriptions supply heading level, quote depth and divider identity, and dividers occupy one display atom. Existing delimiter, indentation, closer and line-ending spelling survives opening and edits elsewhere. → crates/futo-notes-editor/src/inline/blocks.rs, crates/futo-notes-editor/tests/blocks.rs
- Heading/Text and explicit Quote commands apply to the visible lines touched by the supplied selection; Quote adds or takes off one quote level, and a quote changes level only through it: Indent and Outdent leave plain quote lines, paragraphs, headings and tables alone (their buttons stay visible but greyed out, `can_indent`/`can_outdent` false), nest and un-nest list items (list-indent.md), and put a tab on or take one off the lines of a code block (fenced-code.md). Quote uses the generic row edit (lists.md). Changing heading/Text retains enclosing quotes, while choosing Quote on an unquoted heading makes it quoted paragraph text. Blank separators keep neighboring lazy-continuation lines outside the requested quote change. A command is one protected source edit and exact Undo action; an already-selected heading level is a no-op, while Quote on text that is all quoted — quoted paragraphs, headings and list items alike — takes one level off and keeps each line's block (the toolbar button toggles). → crates/futo-notes-editor/src/session/blocks/list_edit/ops.rs, crates/futo-notes-editor/src/session/blocks/mod.rs `all_quoted`, crates/futo-notes-editor/tests/blocks/toggle.rs, crates/futo-notes-editor/tests/lists/command_eligibility.rs
- Tapping H1, H2 or H3 when every touched line already carries that level turns those lines into Text while preserving enclosing quotes; a mixed selection takes the requested heading level. This toolbar toggle is one exact Undo action; the portable explicit Heading command retains its no-op behavior. → crates/futo-notes-editor/src/session/blocks/commands.rs `ToggleHeading`, crates/futo-notes-editor/tests/blocks/toggle.rs
- Blank lines in a multi-line selection are set aside by Heading/Text: they gain no heading and are not counted when the toggle decides whether every touched line already carries the level, whatever quote depth or block kind the other lines sit in. Front matter is set aside by both. Quote's all-quoted test sets blank lines aside too, along with code and divider lines, which no Quote command changes, so quoted lines around a blank, a `>`-only line, a divider or a code block toggle off; Quote on unquoted text still quotes the blank lines between them, keeping one quote (`a\n\nb` becomes `> a\n> \n> b`). Quote decides once, on the selection as given, whether it applies or takes a level off; lifting a touched list item never reverses that. A caret or a selection of only blank lines still formats them. → crates/futo-notes-editor/src/session/blocks/mod.rs `common_heading`, `all_quoted`, crates/futo-notes-editor/tests/blocks/blank_lines.rs
- Quote on Select All in a mixed note quotes eligible heading, inline-formatted, list and table-source rows while retaining fenced code exactly; the parked final empty line stays unformatted and Undo restores the entire action once. → crates/futo-notes-editor/tests/blocks/toggle.rs `select_all_quote_changes_eligible_rows_in_a_mixed_note`
- Heading Enter starts a following paragraph, splitting inline marks at the block boundary; Enter before nonempty heading text leaves a line above and retains the heading. Quote Enter continues the quote one physical line at a time: `> quote` with the caret at its end becomes `> quote\n> ` with the caret on the new quoted line, and a mid-line Enter splits it into `> a\n> b`, with no blank `>` separator line. Enter on an empty quoted line directly under a quoted line drops that line and exits one level (`> quote\n> ` becomes `> quote\n\n` with the caret on the plain line after one blank line; `> > x` leaves a blank `>` line and a `> ` line, then a plain line), and Enter on the empty quoted paragraph after a legacy `>` separator exits one level too. Enter at the first text of the outermost starting quote leaves one line above it, retaining quoted text and caret. A selection is deleted before the structural Enter within the same action. → crates/futo-notes-editor/src/session/blocks, tests/blockquote-continuation.spec.ts, tests/editor-embed-milkdown-interactive-quote-start.spec.ts
- Enter before the text on a later physical line of a quoted paragraph inserts an empty quoted line above it (`> a\n> b` becomes `> a\n> \n> b`); the caret remains before that text and existing neighboring line endings stay exact. Desktop parity gap: the Milkdown editor still saves a quote's Enter as a blank `>` separator (`> hello\n>\n> world`, tests/blockquote-continuation.spec.ts). → crates/futo-notes-editor/tests/blocks/keys.rs
- Divider commands and the line-start `---`, `___ ` and `*** ` shortcuts leave one editable paragraph immediately below the divider, with its caret ready for typing. A necessary `***` spelling prevents a divider after paragraph text from becoming a setext heading. Undo/Redo restores exact source and selection without treating a restored divider as new input. → crates/futo-notes-editor/tests/blocks.rs
- Line-start heading (`# ` through `###### `) and quote (`> `) shortcuts convert only their current line; Undo takes back the triggering keystroke while earlier typed markers remain visible. Speculative markers use local literal spelling where necessary so reopening agrees with the displayed text before conversion; opening existing raw markers still follows CommonMark. → crates/futo-notes-editor/src/session/blocks, crates/futo-notes-editor/src/inline/spelling.rs
- In a bullet or ordered item, `# ` through `###### ` or `> ` typed at the start of the item's text opens a heading or quote inside that item, which CommonMark reads and the editor displays (`2. second step` becomes `2. ## second step`; an empty item becomes `- ## `, `- > `); the item keeps its marker and its list, and Undo takes back the triggering space as above. After a task checkbox, where GFM reads no heading or quote, the marker stays literal text and the space lands (`- [ ] ## Day`). The explicit Heading and Quote commands still lift a list item out of its list first. → crates/futo-notes-editor/src/session/blocks/typing.rs `marker_in_item`, crates/futo-notes-editor/tests/blocks/conversions.rs
- Block commands and shortcuts preserve literal body punctuation, including heading-like leading text and visible trailing hashes; a new block boundary locally closes and reopens multiline inline marks. Multiline inline code remains one visible line when a block command changes that line, preserving exact neighboring source and exact original bytes on Undo. → crates/futo-notes-editor/tests/blocks/commands.rs, crates/futo-notes-editor/tests/blocks/conversions.rs
- Heading and quote Enter retain carried inline formatting for the next typed character in an empty continuation; block formatting retains explicitly carried formats, and ordinary typing keeps inline markers on their own side of an existing structural boundary. → crates/futo-notes-editor/tests/blocks/keys.rs, crates/futo-notes-editor/src/inline/edit.rs
- Structural keys derive inline affinity from their supplied input range when it differs from the stored selection; an explicit carried-format override belongs only to its matching caret, and Undo restores that original caret and override. → crates/futo-notes-editor/tests/blocks/keys.rs, crates/futo-notes-editor/src/session/blocks/keys.rs
- Structural commands commit pending marked text before applying the command through the composition owner's staged transaction: one acceptance covers both changes, while commit and command retain distinct Undo steps. Native and WASM consumers forward ranges and command intent and render engine block descriptions without parsing Markdown. → crates/futo-notes-editor/src/session/composition.rs
- Heading conversions preserve visible leading body whitespace and valid display selections; Text removes hidden ATX indentation. Multiline quoted setext headings hide every physical quote prefix, including after Text removes their shared underline. → crates/futo-notes-editor/tests/blocks/commands.rs, crates/futo-notes-editor/tests/blocks/projection.rs
- Setext heading bodies retain literal hashes that do not form a valid ATX opener; quote-depth commands preserve every owned physical body and underline prefix. Heading Enter maps the staged visible body caret without exposing those prefixes, including later-line and end carets with CRLF and Unicode. Deleting the complete setext body retires its dependent underline into the equivalent empty ATX heading; Enter then starts a following paragraph, including inside quotes, while empty ordinary quoted paragraphs still exit one level. → crates/futo-notes-editor/tests/blocks/projection.rs, crates/futo-notes-editor/tests/blocks/commands.rs, crates/futo-notes-editor/tests/blocks/keys.rs
- A changed heading level applies to the entire touched semantic heading, folding its owned soft line boundaries to one ASCII space and mapping the selection through that change; choosing its existing level leaves exact source unchanged. Divider and Enter stage the actual visible body with inline identities and physical container spelling, while local input repairs newly exposed heading whitespace, literal hashes and closers. Their returned carets accept the next character without a selection echo, and Undo/Redo and a saved reopen retain exact source. → crates/futo-notes-store/src/tests/editor_session/list_actions.rs
- Quote-prefix changes retain unchanged inline bodies across owned heading soft lines; actual new block seams preserve visible line-end whitespace and literal backslashes. An existing heading level is an exact no-op before any seam spelling. → crates/futo-notes-editor/tests/blocks/seams.rs
- Input that makes an empty nested quote nonempty inserts the necessary blank quoted separator before a lower lazy neighbor, preserving that neighbor's exact heading spelling. Compound and OS replacements map each later opening-display target and the final native caret through the actual staged replacements, including unchanged same-line spaces and later source outside the edited window. → crates/futo-notes-store/src/tests/editor_session/seams.rs
- Ordinary typing retains its normal history grouping through a necessary quote separator or divider-edge paragraph insertion, including a preceding adjacent run and carried inline formats; explicit isolated input and structural commands keep their own history boundaries.
- Marked text remains a raw provisional overlay without an automatic separator; cancel leaves accepted source unchanged. Protected commit inserts the necessary quote boundary once, and following OS input maps its originally changed provisional runs through that commit while preserving newly protected separators in unchanged runs. One append protects commit plus following input while their exact Undo steps remain separate. → crates/futo-notes-editor/src/session/composition.rs, crates/futo-notes-editor/tests/fixtures/structural-seams.json
- Explicit multi-run input during composition retains the supplied ranges through protected commit; equal visible scalars with different entity, escape or literal source spellings keep their selected and unselected identities. Unchanged marking, distant targets and quote separators follow the same one-acceptance and separate-history contract. → crates/futo-notes-editor/tests/compound_composition.rs, crates/futo-notes-store/src/tests/editor_session/seams.rs
- A replacement spanning selected body text and a complete lower setext body may retire that lower body's dependent heading syntax to reproduce the supplied display; a separator-only selection grants no preceding body ownership, and a partially selected lower body retains its unselected structure. Direct and explicit input preserve untouched neighboring bytes, one acceptance, exact native carets and history; marked text remains raw until protected input. → crates/futo-notes-editor/tests/blocks/selected_source.rs, crates/futo-notes-editor/tests/fixtures/structural-seams.json

- Typing on the plain blank separator immediately after a quote retains a blank source separator before the new plain text, keeping both that text and the following paragraph outside the quote. The separator and input are one accepted edit and Undo action, including an IME composition commit. → crates/futo-notes-editor/src/session/blocks/typing.rs
