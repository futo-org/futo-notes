# Heading, quote and divider block commands

Each line is read on its own (linedown.md): a heading is `#` to `######` and a space at column 0
after any quote markers, a quote is one or more `>` (`>>` or `> >` nests), a divider is a top-level
line such as `---`. These commands rewrite the start of the lines they act on and leave the text
alone. → crates/futo-notes-editor/src/engine/commands/blocks/

## Commands

- Heading and Text (the explicit Heading 1–6 and Text commands) act on every line the selection touches; a selection ending at the very start of a line does not touch it. Blank lines are set aside unless every touched line is blank, and code, front matter, dividers and tables are never changed. → crates/futo-notes-editor/src/engine/commands/blocks/mod.rs `targets`, crates/futo-notes-editor/tests/fixtures/engine/blocks.json
- A heading keeps the line's quote markers (`> title` becomes `> # title`); a list item loses its marker and task box (`1. a` becomes `## a`, `> - [ ] a` becomes `> ## a`); an indented plain line loses its indent; leading spaces in the text stay. → crates/futo-notes-editor/src/engine/commands/blocks/mod.rs `as_heading`
- Text takes the heading or list marker off and keeps the quote markers. Nothing else is written, unless the text left behind would read as another block: then one `\` keeps it plain (`- # todo` becomes `\# todo`, `- 1. a` becomes `1\. a`, `# ---` becomes `\---`). No blank line is added around the line. → crates/futo-notes-editor/src/engine/command.rs `kept_line`
- Choosing a line's current heading level changes nothing and leaves no Undo step. The toolbar's heading toggle (`ToggleHeading`) instead turns the lines to Text when every touched line already has that level, and otherwise sets it. → crates/futo-notes-editor/src/engine/commands/blocks/mod.rs `block_toggle`
- Quote decides once, on the touched lines with text (all of them if all are blank): when every one is quoted, it takes one quote level off every quoted touched line, each keeping its block (`> ## a` becomes `## a`, `> - a` becomes `- a`, `> > a` and `>> a` become `> a`, an empty `>` line becomes an empty line). Otherwise it adds one level to every touched line from the first line with text to the last, blank lines between them too (`a\n\nb` becomes `> a\n> \n> b`), and a heading or list item becomes quoted text (`## Title` becomes `> Title`, `- item` becomes `> item`). → crates/futo-notes-editor/src/engine/commands/blocks/mod.rs `quote`, `quoted`, `unquoted`
- Quote never changes code, front matter or dividers, and they do not stop quoted lines around them from toggling off. It quotes table lines as text; a table it would leave without its header or delimiter row is left as it was. A line under a quoted line is not part of that quote, so Quote on it quotes only it. → crates/futo-notes-editor/src/engine/tests/blocks.rs `quote_on_a_whole_table_quotes_it_and_the_guard_keeps_a_table_whole`
- Taking a quote level off writes one `\` where the line would otherwise read as another block (`> ---` becomes `\---`, ```` > ``` ```` becomes ```` \``` ````). → crates/futo-notes-editor/src/engine/commands/blocks/mod.rs `unquote`
- The toolbar shows the heading level every touched line with text shares (0 for text) and whether Quote would take a level off, by the same rules the commands use, so a lit button's tap takes its format off and an unlit one's never does. → crates/futo-notes-editor/src/engine/surface.rs `toolbar`, crates/futo-notes-editor/src/engine/tests/blocks.rs `a_lit_toolbar_button_takes_its_format_off_and_an_unlit_one_never_does`
- Divider writes `---` at the caret, the selection removed first. Text before the caret stays on its line above the divider; text after it moves to a plain line below at the same quote depth, where the caret lands; with none, the caret lands on a new empty line below (in the line's quote). No other blank line is written. A heading split by a divider keeps its level above; a caret at a line's text start puts the divider above the whole line. → crates/futo-notes-editor/src/engine/commands/blocks/divider.rs
- A divider is never quoted: inside a quote it sits at column 0 between the quoted lines (`> ab` becomes `> ab\n---\n> `). Divider changes nothing in code, front matter or a table. → crates/futo-notes-editor/src/engine/commands/blocks/divider.rs
- Where a `---` would make line 1 open front matter (line 1 is a `---` divider, or the divider goes on line 1 with a `---` line below), Divider writes `----`, which is a divider and closes nothing. → crates/futo-notes-editor/src/engine/commands/blocks/divider.rs `divider_mark`
- Every command is one host acceptance and one exact Undo step that restores the bytes and the selection; Redo restores the edit. The selection follows its text, and a caret never lands between a `\` the command wrote and the character it escapes. A command that would change a line it did not act on (a fence, front matter or table opened or closed) is cancelled with no edit and no history. Pending marked text commits first as its own Undo step. → crates/futo-notes-editor/src/engine/command.rs `Engine::run`

## Keys on heading and quote lines

Keys on list items belong to the list commands (lists.md); keys elsewhere edit text as typed.

- Enter in a heading splits it: the text after the caret moves to a plain line below at the same quote depth (`# Ti|tle` becomes `# Ti\ntle`), with a `\` where that text would read as another block. Enter at the end leaves an empty plain line below. → crates/futo-notes-editor/src/engine/commands/blocks/keys.rs `block_enter`
- Enter at the start of a heading's or quoted line's text opens an empty line above it, and the line keeps its block and the caret; the new line holds the line's quote markers when the line above it is quoted (`> a\n> b` becomes `> a\n> \n> b`). → crates/futo-notes-editor/src/engine/commands/blocks/keys.rs `block_enter`
- Enter in a quoted line continues the quote one line at a time, with the quote markers as typed: `> quote|` becomes `> quote\n> |`, `> a|b` becomes `> a\n> b`, `>> a|b` becomes `>> a\n>> b`. → crates/futo-notes-editor/src/engine/commands/blocks/keys.rs `block_enter`
- Enter on an empty quote line (`> `, `>` or `> > `) takes one quote level off that line and writes no other line: `> quote\n> |` becomes `> quote\n|`, `> > x\n> > |` becomes `> > x\n> |`. → crates/futo-notes-editor/src/engine/commands/blocks/keys.rs `block_enter`
- Enter splits inline marks the caret is inside: they close before the break and open again after it, and the caret stays after them (`# **ab|cd**` becomes `# **ab**\n**cd**`; a link is split into two links). A caret at a mark's text start or end moves the whole mark to one side. List items and plain lines split marks the same way (lists.md, inline-formatting.md). → crates/futo-notes-editor/src/engine/commands/marks.rs `split`
- Enter and Shift+Enter act alike here, remove a selection first in the same action, and write the caret line's own line ending (CRLF on a CRLF line). Each is one Undo step. → crates/futo-notes-editor/src/engine/commands/blocks/keys.rs
- Backspace at a heading's text start makes it Text, keeping its quote markers. → crates/futo-notes-editor/src/engine/commands/blocks/keys.rs `block_backspace`
- The joining Backspace (iOS sends it for every caret Backspace) joins a heading to the line above instead: an empty line above is removed; text, a list item or a heading above takes the heading's text at its end; code above (behind its closing fence) takes the heading's shown text on its last line, as code (an empty code block gains that line). A heading on the first line, or under a divider, table or front matter, becomes Text. Away from a heading's text start it is an ordinary Backspace. → crates/futo-notes-editor/src/engine/commands/blocks/keys.rs `join_heading`
- Backspace at a quoted line's text start, under a quoted line of the same depth, joins it: under text or a list item the text joins that line's end; under an empty quote line, that line is removed. Otherwise (first line of a quote, under a heading, or under a line of another depth) it takes one quote level off the line, with a `\` where needed. → crates/futo-notes-editor/src/engine/commands/blocks/keys.rs `block_backspace`
- Delete at a quoted line's end and Backspace or Delete across a heading's line break edit as typed: the joined line's markers go with the line break (`> a|\n> b` becomes `> ab`). → crates/futo-notes-editor/src/engine/edit/plan.rs `plan`

## Typing

- Typing `# `, `> ` or `---` makes a heading, quote or divider because that is how the line reads; nothing converts the line, escapes it or writes anything else. A lone `#` is saved as `#`, a plain line. → crates/futo-notes-editor/src/engine/edit/, docs/spec/editor/portable-core/linedown.md
- An empty quote line with no space after its last `>` (`>`, `>>`, `> >`) shows as an empty quoted line, so text typed there that as typed would take the line out of its quote (`>x` is a plain line) gets the space the quote needs first, as Enter in a quote writes `> `: `>` then `x` writes `> x`, `> >` then `x` writes `> > x`. A typed space, tab, line break or `>` lands as typed. Carried formats apply to the text after the space, and a selection, a text service's text or a composition landing there takes the space too. → crates/futo-notes-editor/src/engine/edit/plan.rs `quote_space`, crates/futo-notes-editor/src/engine/line.rs, crates/futo-notes-editor/tests/fixtures/engine/blocks.json
