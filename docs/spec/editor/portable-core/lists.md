# List interpretation and editing

A list item is one line (linedown.md, "Lists"). Every list command edits the lines it is pointed at; numbered-list renumbering is the one exception, and names the lines it bumps. Indent and Outdent are pointed at an item and the lines under it (list-indent.md).

- Each item's marker shows as one unit: one U+FFFC at the item's display start, standing for the marker's source from its first character through the space after it, for bullets (`-`, `*`, `+`), numbers (digits then `.` or `)`) and tasks (`- [ ] `, `- [x] `, `- [X] `), whose bullet and box are one unit. The item's indent and quote markers before it stay hidden. → crates/futo-notes-editor/src/engine/line.rs
- A caret stands just before or just after an item's marker unit, never inside it and never before its hidden indent: Left from an item's text start stops before the marker, then goes to the end of the line above. → crates/futo-notes-editor/src/engine/line.rs `allowed`, crates/futo-notes-editor/src/engine/tests/mod.rs
- Opening a note keeps the markers' spelling, indent, numbers and line endings byte for byte. A list description gives each item's source indent in columns, display level from the open ancestor stack (linedown.md, "Lists"), and marker as typed, with no computed number, so views draw `3)` as `3)` and normalize equivalent nesting written with tabs, two spaces or four spaces. The projection also reports the marker unit as a `ListMarker` atom whose range is the unit, so a view draws the marker there from the list description. Indented plain lines borrow the stack's level without adding an ancestor and have no unit. → crates/futo-notes-editor/src/engine/project.rs
- The marker unit acts as its text: a selection that holds it copies and cuts the marker's Markdown; word motion, a double click (which selects the unit alone), grapheme deletion, text-service replacement, composition and find treat it as one opaque unit, Transpose leaves it alone, and format toggles skip it. → crates/futo-notes-editor/src/engine/words.rs, crates/futo-notes-editor/src/engine/commands/transpose.rs, crates/futo-notes-editor/src/engine/commands/inline/draft.rs `gap`, crates/futo-notes-editor/tests/words.rs
- Each list key or command is one Undo action that restores the exact bytes and selection, and one host acceptance. Pending marked text commits first, in the same acceptance and as its own Undo step. A change in display level alone is allowed; the guard compares block kinds. A command that would change how a line it does not name reads (a fence or front matter opening or closing, a table header gained or lost) is cancelled: nothing changes and no Undo step is made. No list shape is refused: `- > b` is a bullet with the text `> b`. → crates/futo-notes-editor/src/engine/command/run.rs `Engine::run`
- Enter and Shift+Enter with the caret before an item's marker write a line break at the line's start, before its hidden indent and quote markers, spelled as the item's line ending (on the note's last line, the one above it): an empty plain line opens above, the item keeps its indent, quotes and marker, the caret stays before the marker, and nothing is renumbered (`1. a\n|2. b` gives `1. a\n\n|2. b`, `- a\n  |- b` gives `- a\n\n  |- b`, `> |- a` gives `\n> |- a`). It is one Undo step. Within one item, a selection starting before the marker is replaced by the line break as typing replaces it. → crates/futo-notes-editor/src/engine/commands/lists/enter.rs, crates/futo-notes-editor/tests/fixtures/engine/lists/marker.json
- Enter and Shift+Enter in an item's text split the item: the text after the caret goes to a new item below with the same quotes, indent and marker, the next number for a numbered item and an unchecked box for a task (the first task keeps its state). The new line takes the item's line ending, or on the note's last line the line ending above it. → crates/futo-notes-editor/src/engine/commands/lists/enter.rs
- Bold, italic, strikethrough, inline code and link text that the split cuts close at the end of the first line and open again on the second; a mark left with no text on one side is dropped there (`- **ab|cd**` gives `- **ab**` and `- **cd**`, `- [te|xt](u)` gives two links). Wikilinks, images and bare URLs are not split into two; their text breaks as typed. → crates/futo-notes-editor/src/engine/commands/lists/enter.rs `left_part`, `right_part`
- With the caret at a nonempty item's text start, Enter opens an empty item above it with the same marker (unchecked for a task, this item's number for a numbered item) and keeps the caret on the item's text: `1. first step\n2. |second step` becomes `1. first step\n2. \n3. second step`; in a list numbered alike the item keeps its number, as below. A selection starting at the text's start does the same once its text is removed. → crates/futo-notes-editor/src/engine/commands/lists/enter.rs
- Enter on an empty item (no text, or only spaces) with no indent takes the marker and box off and keeps any enclosing quote (`> - ` becomes `> `); no blank line is written and nothing is renumbered. On an empty indented item Enter is Outdent (list-indent.md). → crates/futo-notes-editor/src/engine/commands/lists/enter.rs
- Enter with a selection inside one item removes the selected text, then splits. Enter over a selection that spans lines, starting or ending on a list item, removes the selected text and writes one line break: the line the selection ends on keeps its own quotes, marker and block (`- a|\n- b\n> |q` gives `- a\n> q`; a divider the selection ends before stays whole, one it covers goes), and nothing is renumbered. A selection between an item and a fence's line (into a block's code, or out of it) changes nothing. When that changes nothing (the selection holds only a line break and the next line's marker), nothing happens and no Undo step is made. → crates/futo-notes-editor/src/engine/commands/lists/enter.rs `enter_across`
- Reading never renumbers; editing does. Enter in a numbered item writes the next number (a number written with leading zeros keeps its width: `09.` gives `10.`, `01.` gives `02.`). A list numbered alike keeps its number: when the next numbered item below at the same quote depth and indent has this item's number and delimiter, the new item takes that number too (`1. a|\n1. b` gives `1. a\n1. \n1. b`), and on the last numbered item the item above decides the same way (`1. a\n1. b|` gives a third `1.`); a lone item, or one whose neighbor has another number, counts up. Otherwise the numbered items below it at the same quote depth and indent, with the same delimiter, that were counting up in sequence are bumped by one; the walk stops at the first item that was not in sequence. Lines indented further and a fence opened under an item are passed over; a blank line, a line indented less, a bullet, another delimiter or another quote depth ends the walk. These bumps are the only edits a list command makes to lines it was not pointed at. → crates/futo-notes-editor/src/engine/commands/lists/number.rs
- Backspace with the caret at an item's text start (just after its marker), Delete with the caret just before its marker, and deleting a selection of exactly the marker (a key, input of no text, or Cut) take the marker (and a task's box) off: the line stays, as plain text at its own indent inside its quotes (`- a\n  - |b` gives `- a\n  b`). Where the text would then read as another block, one `\` is written before it (`- # todo` gives `\# todo`, `- - a` gives `\- a`). An empty item becomes an empty line, keeping its quotes. Nothing is renumbered. A second Backspace joins the line to the one above, as at any line's start. → crates/futo-notes-editor/src/engine/commands/lists/marker.rs, crates/futo-notes-editor/src/engine/edit/plan.rs `plan`
- A deletion that takes the line break just before an item's marker, and not the marker, joins the item onto the line above and drops its marker: its quotes, indent, marker and box go with the line break and its text continues that line. So Delete at an item's end (`- a|\n- b` gives `- ab`), Backspace with the caret before a marker at its line's start (`para\n|- [ ] b` gives `parab`), and a selection ending just before a marker (`- o[ne\n]- two` gives `- otwo`) all drop it; text typed over such a selection lands at the join. → crates/futo-notes-editor/src/engine/commands/lists/marker.rs `past_joined_marker`, crates/futo-notes-editor/src/engine/edit/plan.rs, crates/futo-notes-editor/tests/fixtures/engine/lists/marker.json
- A deletion that leaves the marker at the start of what shows on its line joins nothing, and the item stays one (`[one\n]- two` at the note's start, or under a blank line, keeps `- two`); a selection that holds the marker removes it as text. → crates/futo-notes-editor/tests/fixtures/engine/lists/marker.json
- The Bullet, Numbered and Task buttons act on every line the selection touches. When every plain line, heading and item among them is already that kind of item, their markers come off as Backspace takes them off. Otherwise each that is not becomes one: plain and quoted lines keep their quotes and indent, a heading loses its `#`s, a bullet keeps its bullet character (`* a` with Task gives `* [ ] a`), a task loses its box under Bullet or Numbered, and a numbered item becomes `- ` under Bullet or Task. A `\` is written where the text would otherwise read as another kind of item (`[ ] x` with Bullet gives `- \[ ] x`). → crates/futo-notes-editor/src/engine/commands/lists/toggle.rs
- Under Numbered each new item counts on from the numbered item above it at its indent (taking its delimiter), or starts at `1.`; the numbered items below the last new one that were counting on from the item above it (or from 1, when there was none) are bumped (`1. a\n|b\n2. c` gives `1. a\n2. b\n3. c`). → crates/futo-notes-editor/src/engine/commands/lists/toggle.rs
- A list button with a caret on a blank line starts an empty item there (`- `, `1. `, `- [ ] `, inside the line's quotes); in a wider selection blank lines stay blank. Fences, tables, dividers and front matter are left as they are. → crates/futo-notes-editor/src/engine/commands/lists/toggle.rs
- Markers stay as typed: two runs of bullets with different characters stay as they are, and no blank line or separator is ever written between lists. → crates/futo-notes-editor/src/engine/commands/lists/toggle.rs
- The checkbox toggle acts on every task the range it is given touches (a host gives the selection, or a clicked box's line): when any is unchecked all are checked (`[x]`), otherwise all are unchecked (`[ ]`). Only the box's character changes; the engine's selection and affinity stay where they were, also after Undo and Redo. On lines with no box it does nothing. → crates/futo-notes-editor/src/engine/commands/lists/toggle.rs `toggle_task`
- Indent and Outdent on a list item, their Tab and Shift+Tab keys, and the toolbar's `can_indent`/`can_outdent` are specified in [list-indent.md](list-indent.md); typed markers in [list-shortcuts.md](list-shortcuts.md).
- The literal cases (text and selection before and after each key and command, each also undone and redone) are in `crates/futo-notes-editor/tests/fixtures/engine/lists/`; each list key's and button's counted work stays below the old engine's on the `tests/long_regions*` list scenarios. → crates/futo-notes-editor/src/engine/tests/lists.rs
