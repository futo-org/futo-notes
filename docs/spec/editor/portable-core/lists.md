# List interpretation and editing

- Bullet (`-`, `+`, `*`), period/parenthesis ordered markers and checked/unchecked task markers project without revealing source syntax; opening retains their exact spelling, indentation, lazy numbers and line endings. List descriptions supply depth, interpreted ordinal, task state and first/continuation-line identity so views do not parse Markdown. → crates/futo-notes-editor/src/inline/lists.rs, crates/futo-notes-editor/tests/lists.rs
- Canonical list, quote and ATX prefixes are interpreted in physical source order, including same-line nested syntax and quotes after wide or tab-padded list markers; indentation uses physical tab columns at each container origin. Task-body `>` and `#`, escaped markers and code contents remain literal unless their actual canonical events classify them as structure. → crates/futo-notes-editor/src/inline/blocks.rs
- Explicit Text on a same-line list item containing a quote retains its empty paragraph before that quote, exact outer quote spelling and line endings; an unselected preceding listed sibling does not add a second synthetic paragraph separator. A following list keeps its own canonical ownership and untouched marker bytes. → crates/futo-notes-editor/src/session/blocks/list_commands/marker.rs
- Same-line quoted-header changes preserve both selection affinities and interior UTF-16 positions within complete unchanged decoded source atoms, including entities whose source and display have equal byte lengths and general crossquote lifting through three or more header groups. One actual-row preview validates complete raw retention, the final canonical segment and planned list/plain ownership before host acceptance; rejection preserves real source, history and selection, and the preview invokes no host, clock or history action. → crates/futo-notes-editor/src/inline/retained_points.rs, crates/futo-notes-editor/src/session/blocks/list_commands/selection.rs
- For complete single-line quoted list bodies, nearest Outdent retains an empty paragraph when removing the final inner quote creates a parallel paragraph; registered Backspace merges the quoted body into the nearest preceding empty list paragraph, including consecutive quote barriers after that header. Unchanged implicit list parents keep compact prefixes, and a surviving inner quote does not create an extra physical empty line. A newly empty shared bullet header uses the existing alternate-marker policy when its unchanged spelling would become a thematic break. → crates/futo-notes-editor/src/session/blocks/list_prefix_frames/mod.rs
- Multiline quoted root-list paragraphs apply nearest Outdent or registered Backspace to the complete canonical textblock, retaining explicit or lazy body spelling and authored LF/CRLF. Outdent retains its parallel empty paragraph; Backspace merges into the preceding empty paragraph. Later paragraphs, fences, foreign items and their line endings remain unchanged, and retained entity endpoints keep their exact native positions through rejected acceptance and Undo/Redo. → crates/futo-notes-editor/src/session/blocks/list_prefix_frames/mod.rs, crates/futo-notes-editor/src/inline/blocks_paragraph.rs
- Full Text keeps the earlier same-quote empty list parent and the lifted empty paragraph before its retained inner quote; crossing a quote promotes the enclosing empty paragraph before that quote. Nearest key/Outdent intent remains distinct from full Text lifting, including multiline bodies and tight-list inline textblocks. → crates/futo-notes-editor/src/session/blocks/list_lift.rs, crates/futo-notes-editor/src/session/blocks/list_lift_crossquote/mod.rs
- Full Text retiring a complete shared physical chain of list/quote headers keeps one representable root empty paragraph before the surviving quotes. Leading empty paragraphs inside those quotes follow the existing Markdown reopen rule and are not persisted with private syntax. Shared physical bodies are protected once per command; canonical item queries and prefix/column planning do not repeat a complete body for each quote ancestor. → crates/futo-notes-editor/src/session/blocks/list_lift_crossquote/mod.rs, crates/futo-notes-editor/src/session/blocks/list_lift_crossquote/cuts.rs, docs/spec/editor/paragraphs-and-lines.md
- Promoting a complete root list item with paragraph continuation and one or more fenced blocks retires only its container-owned prefix columns, preserving relative fence indentation, opaque code blank spaces/tabs, delimiter width, language and line endings. The final unmatched fence receives a closer before a proven foreign scope when removing the original list boundary would expose that scope; an existing closer, genuine document EOF or retained inner quote boundary stays distinct. Code Enter and literal list punctuation remain opaque after promotion. → crates/futo-notes-editor/src/session/blocks/list_fence_promotion/mod.rs, crates/futo-notes-editor/tests/lists/fence_promotion.rs
- Promoted parent prose after an adjacent listed paragraph gains only the blank needed to retain root ownership; existing blanks, empty list padding and opaque predecessors keep their exact source. Exact stages inherit an original physical start-edge prose fact without copying foreign bodies or dereferencing outside coordinates; derived or clipped contexts cannot invent that authority. → crates/futo-notes-editor/src/session/blocks/list_fence_promotion/boundary.rs, crates/futo-notes-editor/src/session/staging.rs
- Heading and Quote preserve the established plain, same-quote and cross-quote list-lifting distinction; Quote within an already quoted nested item leaves source, host and history unchanged. A following nonempty first bullet or ordered-one list interrupts a new quote paragraph itself; a following ordered start that cannot interrupt keeps a real quote-scope blank and its unchanged marker rather than gaining an empty item. → crates/futo-notes-editor/src/session/blocks/content.rs
- Quoted CRLF task retargets use the actual tabbed content column before the checkbox while preserving continuation spelling, nested code language/body, child-list depth and the following owner's ordinal.
- Fence promotion validates the candidate code display and outside canonical meaning before one host acceptance. Exact source windows inherit certified original physical edge facts independently of complete-original-item ownership; trimming an item's opening invalidates its ownership certificate even at genuine EOF; transformed bodies and uncertified staged interiors cannot turn local parser endpoints or absent visible neighbors into original EOF or foreign-owner proof. Unproved promotion rejects before source, history or selection changes. → crates/futo-notes-editor/src/session/staging.rs, crates/futo-notes-editor/src/session/blocks/list_fence_promotion/origin_tests.rs
- Promoting an inner-quote code tail before a separately owned foreign quote retains both quote owners and the exact opaque body. A missing unquoted physical blank gains one matching line ending; an existing gap retains its bytes without duplication, and no unnecessary fence closer is added. This applies through complete exact staged windows with certified original ownership; transformed or clipped opaque source rejects before host acceptance. → crates/futo-notes-editor/src/session/blocks/list_fence_promotion/origin_tests.rs
- List Enter splits the visible inline body with one protected action, retaining the leaving task's state and starting the new task unchecked; splitting at a checked task's text start leaves the new unchecked empty item above its retained checked text. A text selection is removed before the split, and an empty list/task item exits its list while retaining an enclosing quote. → crates/futo-notes-editor/src/session/blocks/lists.rs, crates/futo-notes-editor/tests/lists.rs
- An ordered split renumbers its actual list together with the split in one exact Undo/Redo action, retaining its first number and delimiter; unrelated lists and content retain their exact bytes. Ordinary text input retains lazy numbering, and loose lists remain one semantic owner across their blank and continuation lines. → crates/futo-notes-editor/tests/lists.rs
- Checkbox commands target a task marker while preserving the active text selection and carried formats; pending composition commits before the checkbox action through one protected acceptance, with separate exact Undo groups for the marked text and checkbox change. → crates/futo-notes-editor/tests/lists/fixtures.rs, crates/futo-notes-store/src/tests/editor_session/list_actions.rs
- Bullet, ordered and task commands retarget the complete touched list; repeating its current kind lifts only the selected items and their physical continuation lines. Heading-to-list conversion retires the old heading marker, optional closing hashes or setext underline while retaining the inline body and final line ending. → crates/futo-notes-editor/src/session/blocks/list_commands/mod.rs, crates/futo-notes-editor/tests/lists/commands.rs
- Explicit Text and a repeated list-kind command lift the selected nested item through its list ancestors while retaining quote ancestry; same-quote earlier parent text stays listed, whereas crossing an intervening quote promotes the enclosing outer item. Descendants and unselected sibling fragments retain their own list ownership, with only the separators and marker changes needed to spell that ownership. → crates/futo-notes-editor/src/session/blocks/list_lift.rs, crates/futo-notes-editor/src/session/blocks/list_lift_crossquote/mod.rs, crates/futo-notes-editor/tests/lists/lifting.rs
- A selection spanning different block formats applies the explicit command to each original format run in source order within one protected acceptance. Whole-owner retargeting and exact selected-item retirement coexist; selecting a retiring ancestor and its descendant in one run keeps that descendant listed after the ancestor becomes a paragraph. Undo restores exact original source, selection and affinity. → crates/futo-notes-editor/src/session/blocks/list_targets.rs, crates/futo-notes-editor/src/session/blocks/list_lift_plan.rs, crates/futo-notes-editor/tests/lists/mixed_commands.rs, crates/futo-notes-editor/tests/lists/ordered_tasks.rs
- An explicit list command on a bare quoted paragraph creates a root list; converting a heading inside a quote or retargeting an existing quoted list retains its quote. Typed list shortcuts keep their quoted context. → crates/futo-notes-editor/tests/lists/mixed_commands.rs, src/features/editor/milkdown/blockCommands.preset.test.ts
- Explicit Ordered on an ordered task owner removes checkbox state while retaining its start, delimiter, raw padding and lazy physical numbers. When a later run lifts a child into a paragraph and splits that owner, each newly independent following fragment copies the owner's original start; only its first physical number changes when required, and a non-one start receives the paragraph separator needed for its canonical list ownership. Foreign owners keep their exact bytes and interpreted starts. → crates/futo-notes-editor/tests/lists/ordered_tasks.rs, crates/futo-notes-editor/src/session/blocks/list_lift_plan.rs
- A typed triggering space converts `-`, `+` or `*`, a period ordered start of at most nine digits, or `[ ]`/`[x]` within a list item; Undo restores the exact pre-trigger source. Opening an authored uppercase `[X]` task is supported; typing it remains literal. Inline code and raw marked composition do not trigger these shortcuts. Ten or more digit starts, including leading zeroes, remain literal. → crates/futo-notes-editor/src/session/blocks/list_typing.rs, crates/futo-notes-editor/tests/lists/input.rs, crates/futo-notes-editor/tests/fixtures/list-actions.json
- Ordered Enter supports the maximum nine-digit start and greater interpreted following ordinals by spelling overflowing physical markers as valid lazy `1` markers; ordinary text input never renumbers existing lazy markers. → crates/futo-notes-editor/src/session/blocks/lists.rs, crates/futo-notes-editor/tests/lists/keys.rs
- Creating or retargeting a list prefers a supported alternate delimiter when necessary to preserve neighboring lists' exact marker bytes and interpreted starts. Typed shortcuts join a preceding bullet list, or an ordered list only when the typed number is its interpreted next ordinal; a following list stays independent. Style and boundary intent use canonical local interpretation plus original outside context across transparent blank paragraphs, including nested inline-seam and composition stages; fixed-size boundary witnesses distinguish a temporary edge from real EOF, and local edits remain authoritative. Metadata summaries skip unrelated blank subtrees and foreign bodies. This intent is retained for an empty newline-terminated body when removing the typed prefix temporarily makes its blank row a preceding list continuation. If both ordered delimiter styles conflict, one standalone standard empty HTML comment separates the required boundary; a middle empty-item exit also retains such a boundary so reopening cannot reunite its two list halves. → crates/futo-notes-editor/src/session/blocks/list_styles.rs, crates/futo-notes-editor/src/session/blocks/lists.rs, crates/futo-notes-editor/tests/lists/comment_seams.rs
- Canonical projection hides standalone newline-terminated `<!-- -->` and `<!---->` block-comment lines, including their line endings and enclosing quote prefixes; existing authored comment bytes survive ordinary editing and exact Undo/Redo. This narrow standard grammar supports independent list identity because blank lines alone do not separate same-kind CommonMark lists; other raw HTML follows its own block rules (foreign-content.md). Inline comments, meaningful HTML, code contents and an EOF comment without its terminating newline retain their existing interpretation. → crates/futo-notes-editor/src/inline/empty_comments.rs, crates/futo-notes-editor/tests/lists/comment_seams.rs, https://spec.commonmark.org/0.31.2/#example-308
- The unchanged seventy-four original shared synthetic list cases, thirty-five nested-container cases, twenty-seven container-command cases, fourteen list-header cases, forty prefix-frame cases and twenty-three fence-container cases and five heading/quote-command cases carry literal source, display, native UTF-16 ranges, interpreted item ordinals/check states and exact history groups in six source consumers: editor, actual store, UniFFI, compiled WASM, Swift and Kotlin. Native source registration does not establish execution of current native binaries; these literals are not OS input captures or latency measurements. Store controls include failed append, paused retry, failed Undo, flush, modeled power loss, recovery and checkpoint/reopen. → crates/futo-notes-editor/tests/fixtures/list-actions.json, crates/futo-notes-editor/tests/fixtures/list-shortcuts.json, crates/futo-notes-editor/tests/fixtures/list-staging.json, crates/futo-notes-editor/tests/fixtures/prefix-frame-commands.json, crates/futo-notes-editor/tests/fixtures/fence-container-commands.json, crates/futo-notes-editor/tests/fixtures/heading-quote-commands.json, crates/futo-notes-store/src/tests/editor_session/list_actions.rs, crates/futo-notes-ffi/tests/editor_list_actions.rs
