# Opt-in bounded code preparation

- An opt-in bounded owner retains the same exact-source session and offers single-scalar non-newline, non-fence-marker insertion inside an authoritatively retained top-level closed fence; explicit entry prepares indexed certificates, supported keys neither parse nor materialize the giant row, and unsupported or invalid input rejects before acceptance. Existing full-return methods and paragraph projections remain unchanged. → crates/futo-notes-editor/src/session/bounded.rs
- For a certified independent small-paragraph suffix, removing an existing closer progressively supplies revision-tagged semantic/map replacements, including unchanged visible text, bounded current-display far selection, and live certified code or positive simple-prefix input. Bounded Undo/Redo preserves source ownership; input or direction changes invalidate older continuations, and completion alone adds no source/history action. The finite line index refuses new line breaks and CRLF splits before acceptance. → crates/futo-notes-editor/tests/bounded_progress.rs
- A rejected consuming bounded transfer returns the original usable session, including composition, transient provenance and history; explicit materialization returns that same owner with exact accepted source, original grouping and source-anchored selection, without another acceptance or history action. General paragraphs, containers, tables and wider semantic dependencies, general Store recovery/portable/native consumers and physical latency remain unfinished; this core preparation does not close #313, #314 or #316. → crates/futo-notes-editor/tests/bounded.rs

- Store bounded transfer consumes the full interface over the same attachment, recovery and lease; refusal returns that owner, including composition and history. Accepted recovery is flushed before proportional entry or materialization, and registry materialization retires bounded coordinate authority before later fallible identity work. → crates/futo-notes-store/src/tests/editor_session/bounded.rs
- A consuming source-only worker validates exact source revision, removed bytes and retained canonical operation independently of page frames, selection, history grouping and clocks; it accepts finite literal, closer and contiguous-source-suffix inverse witnesses without full projection. Dirty suffix source effects prevent retained closer restoration until certified inverse cancellation or explicit materialization; unsupported older inverses require materialization. Worker materialization preserves source provenance but explicitly ends its history lifetime, while native/page materialization preserves page history. → crates/futo-notes-editor/tests/bounded_source.rs
- Portable bounded entry freezes a ready Full page before consuming the worker mode; a canceled uncommitted handshake restores the original Full request receipt, while committed mode return retires old request authority. Source acceptance uses host incarnation and exact source witnesses independently of page-local cursor generations. → crates/futo-notes-store/src/tests/editor_session/portable_bounded.rs
- Append, Flush, pause and a retained rejected candidate block bounded selection/progress callbacks; candidate copying preserves prepared source and raw refused callbacks retain their original coordinates rather than being rebased. A Full handoff waits for acknowledged accepted-prefix durability before proportional page work, preserves pending source and emits a real canonical whole-display reset only through the legacy Resume/retry acceptance barrier, including a lost successful reply. → crates/futo-notes-editor/src/portable/bounded/materialize.rs
- Compiled WASM uses the same page engine, typed bounded handshake and real source-only Store worker; native/page history survives materializing return, while worker-only source authority ends its history lifetime. This development transport does not establish renderer/IME or physical latency/durability acceptance. → crates/futo-notes-editor/tests/wasm-bounded-consumer.mjs

- Each bounded source/presentation attempt and explicit mode transfer replaces the latest-operation work receipt, including preaccept refusal and wrapper validation; successful calls mirror their returned work, and refused consuming transfers retain spent work with the original usable owner. Receipt queries bypass pause, pending, cursor and reset guards; a separate query observes the latest completed attempt for a serialized caller, without atomic pairing across competing calls. → crates/futo-notes-editor/tests/bounded_receipts.rs
- Refused source inverses and historical groups retain actual inspected source, payload copies and metadata visits; Store error acknowledgements carry that work, including the original cached duplicate acknowledgement. Proportional materialization charges both retained source-record passes and each Redo group and entry moved into Full history. Core counters exclude Rope/allocator internals and JSON/binding serialization or lifting; page UTF-16 decoding is charged, and native output conversion remains a separate report. → crates/futo-notes-store/src/tests/editor_session/portable_bounded.rs
