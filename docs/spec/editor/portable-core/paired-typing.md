# Paired typing

What a typed backtick, and Backspace, do when the host opts in. Each rule reads only the text around the caret, never what was typed before it. Cases: `crates/futo-notes-editor/tests/fixtures/engine/paired-typing.json`.

- Paired typing is the input action `PairedTyping` (Rust `InputAction`, FFI `EditorInputAction`, the WASM payloads' `InputAction`). A host opts in by sending it for a plain typed key; desktop sends it for a typed backtick, phones do not, and compositions, paste and text services never use it. With text other than one backtick, or while text is marked, it is `Typing` exactly. → crates/futo-notes-editor/src/history.rs, crates/futo-notes-editor/src/engine/surface.rs `input`
- At a caret outside code and front matter, with no backtick after it, a backtick writes a pair with the caret between them, as typing writes text there (at a divider's edge, on a line of its own). One Undo step removes both. → crates/futo-notes-editor/src/engine/commands/paired_typing.rs `pair_command`
- A pair is not written where it would make its line an opening fence (only backticks before the caret, after the line's indent, outside a quote): there the backtick is typed as typing types it (`` `|x `` gives `` ``x ``). → crates/futo-notes-editor/src/engine/commands/paired_typing.rs `caret_pairing`
- With a shown backtick after the caret (outside inline code), a backtick writes nothing and the caret moves past it, so a second backtick after a pair ends after both. Nothing is written, so no Undo step. → crates/futo-notes-editor/src/engine/commands/paired_typing.rs `caret_pairing`
- With the caret at an inline code span's text end, before its hidden closing marker, a backtick writes nothing and the caret takes the marker's far side: its display offset stays, its affinity becomes `Forward`, and the next character typed is plain (`` `bar‸` `` then ` baz` gives `` `bar` baz ``). Any hidden marks at that point are passed with it (`` **`a‸`** `` leaves the bold too), and a longer or padded closing marker is passed whole. Before a span's hidden opening marker the caret likewise moves inside the span. No Undo step. → crates/futo-notes-editor/src/engine/commands/paired_typing.rs `caret_pairing`
- On a line that is only spaces or tabs and two backticks, with the caret at its end and no quote, a backtick makes a code block: the line becomes an empty block, an opening fence of three backticks and a closing fence of three backticks at the same indent, in the line's own line ending, which shows as one empty code line. The caret stays at the opening fence's end, so the letters typed next write its language, and changes report `writes_language` ([fenced-code.md](fenced-code.md)). One Undo step. A `- ` or `> ` before the backticks is not an indent, so there it writes a pair. → crates/futo-notes-editor/src/engine/commands/paired_typing.rs `lone_pair_block`
- Over a selection on one line, a backtick turns Code on as the Code toggle does over it (inline-formatting.md), and the selection stays on the text. Over a selection across lines, it does what the Code block command does over it (fenced-code.md). Each is one Undo step. Where the command would turn code off (every selected character is code, or the lines are all code of one block) or changes nothing or refuses, the backtick is typed over the selection as typing types it. → crates/futo-notes-editor/src/engine/commands/paired_typing.rs `paired_selection`, crates/futo-notes-editor/src/engine/commands/inline/mod.rs `inline_code_on`
- In a code block or front matter, inside inline code anywhere but its text end, at a caret that carries Code, and after an escaping `\` (an odd run of them), a backtick is typed as typing types it. → crates/futo-notes-editor/src/engine/commands/paired_typing.rs `caret_pairing`
- Paired Backspace is the paragraph key `PairedBackspace` (Rust `ParagraphKey`, FFI `EditorParagraphKey`, JNI ordinal 7, the WASM payloads' `ParagraphKey`). A host that sends `PairedTyping` sends it for Backspace; phones send `Backspace`, which has no paired rule. → crates/futo-notes-editor/src/session/types.rs, crates/futo-notes-ffi/src/editor/jni_keys.rs
- With a caret between the two backticks of an empty pair (exactly one backtick before it and one after, neither beside a further backtick, outside code, front matter and inline code, not after an escaping `\`), paired Backspace removes both, as one Undo step (`` `|` `` gives `|`). At a heading's text start it follows block-commands.md; anywhere else, over a selection and while text is marked it is Backspace exactly. → crates/futo-notes-editor/src/engine/commands/paired_typing.rs `empty_pair`, crates/futo-notes-editor/src/engine/surface.rs `key`
- Delete has no paired rule: in a fresh pair it removes only the backtick after the caret. → crates/futo-notes-editor/tests/fixtures/engine/paired-typing.json
- A caret move that paired typing makes returns no source edit, so the portable session and WASM answer `null`; the host reads the new selection from the session (`selection`). They do not report affinity: the session keeps it, so input at the same caret lands outside the code span, unless the host first sends the caret again with its old affinity. Native hosts get the affinity in the returned view change. → crates/futo-notes-editor/src/portable.rs `issue_accepted`, crates/futo-notes-editor/tests/portable/unchanged_input.rs
