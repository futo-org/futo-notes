# Long regions on the full path

- A top-level paragraph of at least 2 KiB is cut into rows at sealed soft-line seams: no inline element crosses the seam, the earlier line has no hard-break spelling, the later line cannot start a block, and no row keeps a literal delimiter able to pair across rows. Local keys reparse only neighboring cuts; a change whose meaning reaches across a cut (a setext underline, a list interruption, an unmatched delimiter) widens once to the complete paragraph, including input planning, so the result matches the uncut projection while distant lines keep their exact spelling. → crates/futo-notes-editor/src/inline/row/split.rs, crates/futo-notes-editor/src/inline/split_tests.rs, crates/futo-notes-editor/tests/long_regions.rs
- One literal delimiter able to pair across rows anywhere in a giant paragraph (`2*3`, `a<b`, an unmatched bracket or backtick, a footnote reference) keeps the whole paragraph one row: at 20,000 lines a key there costs about 4.7 M counted work instead of 18 K. A hard-break spelling or a line led by punctuation or an ordered-looking number blocks only the seam beside that line. → crates/futo-notes-editor/src/inline/row/split.rs
- A line of at least 2 KiB without a `|` in such a paragraph (a one-line paragraph, as corpus notes of plain prose often are) is also cut about every 512 bytes inside a space-delimited word of at most 32 ASCII letters (a word seam), which no inline construct, wikilink or literal link reads across; an unmatched `[[` or `]]` keeps the paragraph's lines whole. The rows of one cut line still report it as one block. Input that leaves a seam's word anything but letters, or puts a `|` in its line, plans against the whole line, then the paragraph, and the reparse joins the line again, so the result matches the line-cut projection. At 50,000 characters on one line, a typed key, Backspace, Enter and the Backspace that rejoins the line each cost about their 2,000-character work (note 882329, 11 K: 1.2 KB parsed and 2.3 K metadata items per key instead of 34 KB and 181 K). → crates/futo-notes-editor/src/inline/row/split/paragraph.rs, crates/futo-notes-editor/src/inline/row/split/word.rs, crates/futo-notes-editor/src/inline/split_tests/word_seams.rs, crates/futo-notes-editor/tests/long_regions.rs
- A tight top-level bullet list is cut between top-level items whose content columns match and that nest no list, code or HTML block. List-wide metadata stays exact: each item's owner spans the whole list and the first item after a cut keeps its previous sibling's content column, resolved through an indexed row search rather than a scan. A blank line, marker change or ordered marker inside a cut list widens once to the complete list and leaves it uncut; a list or code block ending a reparsed window keeps its following blank rows. → crates/futo-notes-editor/src/inline/row/split.rs, crates/futo-notes-editor/src/inline/block_queries.rs, crates/futo-notes-editor/src/inline/tree.rs
- A tight top-level list whose items hold only paragraphs, headings and nested lists (no code, quote, HTML, tab or CR) is also cut inside its nested lists, before an item that continues its previous sibling's marker and column at its ordinal number and does not follow a blank line. The row parses synthetic ancestor item lines (one per open ancestor, at its marker and content columns) before its own text and drops their records; a row whose first item no longer continues its context widens back. At 1,000 lines of a two-level outline with links (56 KB) a typed key costs about 22 K counted work and 0.17 ms on a desktop release build instead of 1.3 M and 9.3 ms, and stays there at 20,000 lines (before: 27 M, 360 ms). → crates/futo-notes-editor/src/inline/row/split/list.rs, crates/futo-notes-editor/src/inline/row/context.rs, crates/futo-notes-editor/src/inline/split_nested_tests.rs, crates/futo-notes-editor/tests/long_regions.rs
- When a cut row's context cannot plan the input (a blank line typed into a cut list item, say), planning retries once against the blank-separated piece an uncut row would hold, stopping at front matter. Front matter, raw HTML kinds 6-7 and footnote definitions are never cut; a footnote definition that swallows following rows widens the reparse window in doubling steps. → crates/futo-notes-editor/src/inline/edit.rs, crates/futo-notes-editor/src/inline/window.rs, crates/futo-notes-editor/src/inline/split_tests.rs
- A top-level raw HTML block of kinds 1-5 (`<!--`, `<?`, `<!X`, `<![CDATA[`, `<pre`/`<script`/`<style`/`<textarea`) of at least 2 KiB, unterminated or closed, is cut at line starts; each continuation row parses its block's opener line before its own text and drops the opener's records, and the line after the end condition starts a fresh row. A key that opens, ends or reopens the block reparses its new extent once. A staged command whose window would start inside the block opens it from the opener row instead, a one-off region-sized read. At 20,000 paragraphs inside an unterminated `<!--`, typing, Backspace and Enter each cost about 21 K counted work, as at 1,000. → crates/futo-notes-editor/src/inline/row/split/html.rs, crates/futo-notes-editor/src/inline/row/html.rs, crates/futo-notes-editor/src/inline/mod.rs
- A tight top-level ordered list is cut the same way, only before an item whose physical number equals its ordinal, so each row's own parse numbers its items as the whole list does; a continued row's seam holds while its first number stands, and the following row must continue the delimiter, column and ordinal. Lazy (`1.` everywhere) or otherwise unnormalized numbering stays uncut. Typing and Backspace inside an item stay local (about 18 K counted work at 20,000 items, as at 1,000; before, 1.0 MB parsed). Numbering commands stay whole-list by design: Enter renumbers every following marker (about 2.4 M counted work at 20,000 items), Backspace at an item's start joins through a staged window holding the whole cut list (about 13.7 M), and every staged command's window holds the whole cut list. → crates/futo-notes-editor/src/inline/row/split/list.rs, crates/futo-notes-editor/src/inline/mod.rs, crates/futo-notes-editor/tests/long_regions.rs
- A raw edit whose meaning reaches past its window reparses through it before acceptance: a top-level fence left unclosed at the window end reparses to the note's end; a window that no longer ends a raw HTML block (no blank line before the following row) takes that row; and a list ending the window takes a following row whose first item continues it, or that follows an empty item's blank line. Paste, Store replay and history reach these; the twin fuzz includes raw fence and comment delimiters and requires every step to equal a fresh open. → crates/futo-notes-editor/src/inline/window.rs, crates/futo-notes-editor/tests/reinterpretation.rs
- A top-level fenced code block (backtick or tilde, any info string, CRLF) of at least 2 KiB is cut the same way: each continuation row parses the fence's opener line, indentation included, before its own text. A row the next row continues shows its final line ending as code, a closer row followed by more source shows its break, and the closer line never starts a row, since the final body ending is the hidden frame; a key that closes, reopens or moves the closer to a row start reparses the block's new extent once. Queries resolve a cut fence's opener, body, frame and closer from its first and last rows, and typing without a container prefix checks only the edited lines for a longer fence. At 20,000 code lines, typing, Backspace and Enter each cost about 11 K counted work, as at 1,000 (before: 1.88 M). Fences in lists or quotes stay uncut, and typing on a body line with a stripped prefix (an indented opener) still reads the whole body. → crates/futo-notes-editor/src/inline/row/html.rs, crates/futo-notes-editor/src/inline/block_queries.rs, crates/futo-notes-editor/src/session/blocks/fences.rs
- A top-level table paragraph (every line led by `|`) is cut at line seams like any long paragraph; a `|` line start seals a seam because it starts no block. Unlike other paragraphs, a literal emphasis run inside it does not keep it whole: a key that changes no delimiter run stays local, and one that does reparses the complete table. Paths that need the table layout (in-cell Enter, typed `|`, paste in a cell, row commands) still read the whole table, see tables.md. → crates/futo-notes-editor/src/inline/row/split.rs, crates/futo-notes-editor/tests/table_rows.rs
- Loose lists, lazily numbered ordered lists, quoted containers and fences inside containers remain region-sized on the full path; a single huge display line is one parser unit. → crates/futo-notes-editor/tests/long_regions.rs
- Explicit top-level quotes containing only paragraphs, with each physical line prefixed by `> ` (or an empty `>` line), cut at proven soft-line and paragraph seams. Inline constructs never cross a cut; an unsealed paragraph widens conservatively, and lazy/noncanonical prefixes, nested containers, code and HTML keep their uncut interpretation. Ordinary typing, Backspace and Enter retain their 2,000-line work at 20,000 quoted lines, preserving exact prefixes, neighboring source, composition and Undo. → crates/futo-notes-editor/src/inline/row/split/quote.rs, crates/futo-notes-editor/src/inline/split_tests/quotes.rs, crates/futo-notes-editor/tests/long_regions/quotes.rs

- Repeating Bullet on one middle item reads the selected item and neighboring rows rather than staging its complete tight list; source outside the necessary paragraph separator stays exact and Undo restores the original item. Counted work remains at its 1,000-item size for 20,000 items. → crates/futo-notes-editor/src/session/blocks/list_edit/ops.rs, crates/futo-notes-editor/tests/long_regions/list_toggle.rs

- Whole-note block planning looks up selected physical rows and block boundaries in source order with indexed membership checks; inline-seam detection visits retained spans and binary-searches ordered boundaries instead of comparing every span with every selected line. Counted metadata budgets include these comparisons, and command Undo restores exact original source and selection. → crates/futo-notes-editor/src/session/blocks/commands.rs, crates/futo-notes-editor/src/inline/block_edit.rs, crates/futo-notes-editor/tests/long_regions/block_selection.rs
