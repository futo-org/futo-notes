# Exact source, interpretation and input

- A session opens exact UTF-8 source, including CRLF, trailing whitespace and final-newline spelling; opening and dropping an unchanged store session writes neither the note nor a recovery file. → crates/futo-notes-editor, crates/futo-notes-store/src/editor_session
- Insertion, deletion and replacement use distinct source/display UTF-8 byte coordinates; revision-checked conversions expose distinct source/display UTF-16 code-unit ranges for native hosts. Hidden markers and decoded entities have explicit source/display correspondence. → crates/futo-notes-editor/src/coordinates.rs
- Reversed or out-of-range edits, UTF-8 character splits, UTF-16 surrogate splits, unpaired surrogate input and stale revisions reject explicitly before recovery acceptance, leaving text, selection and history unchanged; input preserves exact line endings and Unicode spelling. → crates/futo-notes-editor/src/coordinates.rs, crates/futo-notes-editor/tests/unicode.rs
- Identical selection/affinity echoes retain carried formatting and the typing group; an actual selection or affinity change breaks the run even if the caret later returns. Selection-only updates carry the current source revision and create no source delta, recovery record or history step; Undo/Redo restore the exact selection, affinity and carried formats before/after their original edit. → crates/futo-notes-editor/src/session.rs
- Caret movement and selection collapse stop at extended grapheme boundaries, including combining sequences, joined emoji, flags and CRLF; valid foreign replacement ranges may address code-point boundaries within a grapheme. → crates/futo-notes-editor/src/movement.rs
- Input acceptance holds an exclusive session borrow that prevents synchronous callback re-entry; repeated native notifications using the original revision reject before host acceptance. → crates/futo-notes-editor/src/session.rs, crates/futo-notes-editor/tests/unicode.rs
- Each successful operation returns one ordered display replacement, its resulting selection and the accepted revision; views apply these changes without parsing source. The portable callback is a host acceptance seam, not a WebAssembly durability acknowledgement. → crates/futo-notes-editor/src/types.rs, crates/futo-notes-editor/tests/common/mod.rs
- Consecutive adjacent single-grapheme typing, backward deletions or forward deletions of the same kind join a history group while the injected monotonic clock advances less than 500 ms between accepted inputs; exactly 500 ms, a backward clock movement, a changed selection/affinity, a direction change, a newline or an isolated action starts a new group. Rejected input does not change the group. → crates/futo-notes-editor/src/history.rs, crates/futo-notes-editor/tests/history.rs
- Undo and Redo restore exact source bytes plus opening/resulting selection, affinity and carried formats for the entire group, including local marker repairs; each group travels through one recovery acceptance before one display change. Failed acceptance preserves the whole group and current draft, and a new accepted edit discards the redo branch. → crates/futo-notes-editor/src/session.rs, crates/futo-notes-editor/tests/history.rs
- Replaying a source record while composition is active rejects with `CompositionActive` before host acceptance, so an external record cannot shift a pending marked range; stale revisions still reject first. → crates/futo-notes-editor/src/session.rs, crates/futo-notes-editor/tests/composition.rs
- The legacy `InputAction::CompositionCommit` remains available for hosts that own provisional text themselves; an engine-staged session finishes through `commit_composition` instead. Mixing both ownership modes rejects with `CompositionActive` before acceptance so provisional intermediate text cannot become an Undo step. → crates/futo-notes-editor/src/session.rs
- Marked composition is an engine-owned provisional overlay pinned to an opening committed-display range; repeated updates replace its complete text without changing source, revision, recovery or history. A changed commit applies one isolated protected action; cancel discards only the overlay, and empty, identical or repeated commits create no source record or history step. → crates/futo-notes-editor/src/session/composition.rs
- Ordinary input and compound replacements arriving during composition address the provisional display and commit the marked text plus the replacement through one acceptance; the composition and following input retain separate exact history groups, and further adjacent typing can join the following input group; invalid ranges, malformed foreign text, stale revisions and failed acceptance retain the pending composition and accepted source. Overlay coordinates use a persistent display Rope and materialize only the affected envelope. → crates/futo-notes-editor/src/session/composition.rs
- Formatting during composition commits the pending text before toggling the carried format at the committed caret; Undo/Redo remain inert while marked text is pending, and selection notifications cannot move its pinned edit. An unchanged reconversion still ends at the marked text's end before the next command. → crates/futo-notes-editor/tests/composition.rs
- Text-service replacement derives separate changed character runs from the supplied display range, preserving exact source spelling between corrected words, including hidden delimiters and entities; its caret ends after the supplied replacement, and Undo/Redo restore exact bytes and selection as one action. → crates/futo-notes-editor/src/session/os_replacement.rs
- Dictation placeholders are explicitly tagged ranges within the inserted text containing only U+FFFC; the engine excludes those ranges before committing. Untagged U+FFFC remains literal user content, including existing exact source, and malformed placeholder ranges reject before acceptance. → crates/futo-notes-editor/src/session/os_replacement.rs
- A multi-run replacement supplies nonoverlapping ranges in ascending opening-display coordinates; one action preserves exact unchanged runs, validates every foreign range/string before acceptance and creates one protected recovery record and history step. Its final caret and carried formats follow the final replacement. Compound planning materializes its affected paragraph envelope, never an unrelated note prefix or suffix. → crates/futo-notes-editor/src/session/transaction.rs
- Paragraph Enter and Shift+Enter use the supplied platform display range, insert exactly one LF, and each form an isolated Undo action. Start/middle/end, repeated and empty-line input retain exact untouched CRLF and final-newline bytes through checkpoint and recovery. Headings and quotes use their structural Enter rules; list, fence and table keys remain in their dependent command slices. → crates/futo-notes-editor/src/session/paragraphs.rs, crates/futo-notes-store/src/tests/editor_session/paragraphs.rs
- Paragraph Backspace/Delete remove the supplied selection or one visible extended grapheme in their direction; CRLF is one line-break deletion. Deleting at the document boundary changes neither revision nor history. Each key Undo restores its exact source, selection and carried formatting. → crates/futo-notes-editor/tests/paragraphs.rs
- Formatting survives selection deletion and a single inserted line break; a blank line closes and reopens the inline span locally, retaining carried formatting for the next typed character. Native and WASM paragraph-key consumers forward intent to this same engine without interpreting Markdown or choosing deletion footprints. → crates/futo-notes-editor/src/inline/spelling.rs, crates/futo-notes-ffi/tests/editor_paragraphs.rs
- History remains in-session only: reopening a recovered or checkpointed note starts with no Undo/Redo groups; recovery retains source edits rather than persistent Undo. The store adapts its injected recovery clock into the engine grouping clock. → crates/futo-notes-store/src/editor_session/clock.rs, crates/futo-notes-store/src/tests/editor_session.rs
- Bold, italic, strikethrough and inline code return display text without their markers, semantic runs and source/display correspondence; nested/adjacent runs retain original delimiter spelling outside the necessary edit footprint. Multiline emphasis follows CommonMark, and code contents isolate inline syntax. → crates/futo-notes-editor/src/inline/row.rs, crates/futo-notes-editor/tests/inline.rs
- Selection affinity explicitly chooses the preceding or following visible neighbor at hidden boundaries; native UTF-16 ranges address display text independently of exact source. Caret movement crosses visible graphemes without exposing markers. → crates/futo-notes-editor/src/session.rs, crates/futo-notes-editor/src/coordinates.rs
- Replacing a selection preserves the surviving marks on either side and carries the selection's initial formatting; deleting all marked content removes empty markers while retaining the format for subsequent input. Whitespace at emphasis edges remains visible outside markers until following input can join the span. → crates/futo-notes-editor/src/inline/edit.rs
- Formatting toggles preserve visible text and selection and form one exact-source history action; a collapsed toggle changes carried formatting without writing empty markdown or a recovery record. Candidate verification rejects unsafe formatting before acceptance. → crates/futo-notes-editor/src/session.rs
- When an edit changes CommonMark delimiter flanking, a necessary local boundary repair may encode the immediate adjacent scalar as a numeric entity; the visible scalar, surrounding formats and exact Undo remain intact. Decoded multi-scalar entities support valid code-point replacement ranges without losing the unselected scalar. → crates/futo-notes-editor/src/inline/edit.rs, crates/futo-notes-editor/tests/inline.rs
- Inline-code editing repairs backtick length and padding locally, preserves visible spaces, and splits code around newly inserted literal line breaks; existing code-span line endings project as CommonMark spaces while their exact source bytes remain intact. → crates/futo-notes-editor/src/inline/row.rs, crates/futo-notes-editor/src/inline/edit.rs
- Each source change carries a revision-tagged semantic replacement for its reparsed paragraph window, even if formatting changes leave display text identical; explicit projection queries return semantics and correspondence for a requested display range. → crates/futo-notes-editor/src/types.rs
- Inline source edits, formatting and history use the same store acceptance/replay/checkpoint workflow as plain input; recovery records contain source ranges rather than rendered offsets. → crates/futo-notes-store/src/editor_session/input.rs, crates/futo-notes-store/src/tests/editor_session.rs

- ATX heading levels one through six, setext headings, nested quotes and dividers project without their source markers; revision-tagged block descriptions supply heading level, quote depth and divider identity, and dividers occupy one display atom. Existing delimiter, indentation, closer and line-ending spelling survives opening and edits elsewhere. → crates/futo-notes-editor/src/inline/blocks.rs, crates/futo-notes-editor/tests/blocks.rs
- Heading/Text and explicit Quote commands apply to the visible lines touched by the supplied selection; quote indent/outdent changes one level. Changing heading/Text retains enclosing quotes, while choosing Quote on a heading makes it quoted paragraph text. Blank separators keep neighboring lazy-continuation lines outside the requested quote change. A command is one protected source edit and exact Undo action; an already-selected format is a no-op. → crates/futo-notes-editor/src/session/blocks
- Heading Enter starts a following paragraph, splitting inline marks at the block boundary; Enter before nonempty heading text leaves a line above and retains the heading. Quote Enter splits quoted paragraphs with a quoted blank separator; Enter on the empty quoted paragraph exits one level. Enter at the first text of the outermost starting quote leaves one line above it, retaining quoted text and caret. A selection is deleted before the structural Enter within the same action. → crates/futo-notes-editor/src/session/blocks, tests/blockquote-continuation.spec.ts, tests/editor-embed-milkdown-interactive-quote-start.spec.ts
- Enter before the text on a later physical line of a quoted paragraph inserts its quoted paragraph separator without an extra empty body line; the caret remains before that text and existing neighboring line endings stay exact. → crates/futo-notes-editor/tests/blocks/keys.rs
- Divider commands and the line-start `---`, `___ ` and `*** ` shortcuts leave one editable paragraph immediately below the divider, with its caret ready for typing. A necessary `***` spelling prevents a divider after paragraph text from becoming a setext heading. Undo/Redo restores exact source and selection without treating a restored divider as new input. → crates/futo-notes-editor/tests/blocks.rs
- Line-start heading (`# ` through `###### `) and quote (`> `) shortcuts convert only their current line; Undo takes back the triggering keystroke while earlier typed markers remain visible. Speculative markers use local literal spelling where necessary so reopening agrees with the displayed text before conversion; opening existing raw markers still follows CommonMark. → crates/futo-notes-editor/src/session/blocks, crates/futo-notes-editor/src/inline/spelling.rs
- Block commands and shortcuts preserve literal body punctuation, including heading-like leading text and visible trailing hashes; a new block boundary locally closes and reopens multiline inline marks. Multiline inline code remains one visible line when a block command changes that line, preserving exact neighboring source and exact original bytes on Undo. → crates/futo-notes-editor/tests/blocks/commands.rs, crates/futo-notes-editor/tests/blocks/conversions.rs
- Heading and quote Enter retain carried inline formatting for the next typed character in an empty continuation; block formatting retains explicitly carried formats, and ordinary typing keeps inline markers on their own side of an existing structural boundary. → crates/futo-notes-editor/tests/blocks/keys.rs, crates/futo-notes-editor/src/inline/edit.rs
- Structural keys derive inline affinity from their supplied input range when it differs from the stored selection; an explicit carried-format override belongs only to its matching caret, and Undo restores that original caret and override. → crates/futo-notes-editor/tests/blocks/keys.rs, crates/futo-notes-editor/src/session/blocks/keys.rs
- Structural commands commit pending marked text before applying the command through the composition owner's staged transaction: one recovery acceptance protects both changes, while commit and command retain distinct Undo steps. Native and WASM consumers forward ranges and command intent and render engine block descriptions without parsing Markdown. → crates/futo-notes-editor/src/session/composition.rs, crates/futo-notes-ffi/tests/editor_blocks.rs
- Heading conversions preserve visible leading body whitespace and valid display selections; Text removes hidden ATX indentation, and explicit Quote on an existing quoted heading retires its heading markers and closer while retaining quote depth. Multiline quoted setext headings hide every physical quote prefix, including after Text removes their shared underline. → crates/futo-notes-editor/tests/blocks/commands.rs, crates/futo-notes-editor/tests/blocks/projection.rs
- Setext heading bodies retain literal hashes that do not form a valid ATX opener; quote-depth commands preserve every owned physical body and underline prefix. Heading Enter maps the staged visible body caret without exposing those prefixes, including later-line and end carets with CRLF and Unicode. Deleting the complete setext body retires its dependent underline into the equivalent empty ATX heading; Enter then starts a following paragraph, including inside quotes, while empty ordinary quoted paragraphs still exit one level. → crates/futo-notes-editor/tests/blocks/projection.rs, crates/futo-notes-editor/tests/blocks/commands.rs, crates/futo-notes-editor/tests/blocks/keys.rs
- A changed heading level applies to the entire touched semantic heading, folding its owned soft line boundaries to one ASCII space and mapping the selection through that change; choosing its existing level leaves exact source unchanged. Divider and Enter stage the actual visible body with inline identities and physical container spelling, while local input repairs newly exposed heading whitespace, literal hashes and closers. Their returned carets accept the next character without a selection echo, and Undo/Redo and store recovery retain exact source. → crates/futo-notes-editor/tests/blocks/ownership.rs, crates/futo-notes-store/src/tests/editor_session/blocks.rs
- Quote-prefix changes retain unchanged inline bodies across owned heading soft lines; actual new block seams preserve visible line-end whitespace and literal backslashes. An existing heading level is an exact no-op before any seam spelling. → crates/futo-notes-editor/tests/blocks/seams.rs
- Input that makes an empty nested quote nonempty inserts the necessary blank quoted separator before a lower lazy neighbor, preserving that neighbor's exact heading spelling. Compound and OS replacements map each later opening-display target and the final native caret through the actual staged replacements, including unchanged same-line spaces and later source outside the edited window. → crates/futo-notes-editor/tests/blocks/mapping.rs, crates/futo-notes-store/src/tests/editor_session/seams.rs
- Marked text remains a raw provisional overlay without an automatic separator; cancel leaves accepted source unchanged. Protected commit inserts the necessary quote boundary once, and following OS input maps its originally changed provisional runs through that commit while preserving newly protected separators in unchanged runs. One append protects commit plus following input while their exact Undo steps remain separate. → crates/futo-notes-editor/src/session/composition.rs, crates/futo-notes-editor/tests/fixtures/structural-seams.json
- Explicit multi-run input during composition retains the supplied ranges through protected commit; equal visible scalars with different entity, escape or literal source spellings keep their selected and unselected identities. Unchanged marking, distant targets and quote separators follow the same one-acceptance and separate-history contract. → crates/futo-notes-editor/tests/compound_composition.rs, crates/futo-notes-store/src/tests/editor_session/seams.rs
- A replacement spanning selected body text and a complete lower setext body may retire that lower body's dependent heading syntax to reproduce the supplied display; a separator-only selection grants no preceding body ownership, and a partially selected lower body retains its unselected structure. Direct and explicit input preserve untouched neighboring bytes, one acceptance, exact native carets and history; marked text remains raw until protected input. → crates/futo-notes-editor/tests/blocks/selected_source.rs, crates/futo-notes-editor/tests/fixtures/structural-seams.json
