# Plain Markdown copy, cut and paste

- Copy exports exact source for a display selection. A selection covering a whole display line from its start carries that line's block prefix; a boundary that cuts a bold, italic, strike, code or link span closes or reopens it with that span's original delimiter spelling, outside edge spaces and tabs; a selection of only spaces and tabs gets no delimiters. The first line's nesting indentation is removed from every copied line, and CRLF stays as written. A collapsed selection copies nothing. → crates/futo-notes-editor/src/session/blocks/clipboard/copy.rs, crates/futo-notes-editor/tests/clipboard.rs
- Cut returns the copied Markdown and removes the selection through one accepted edit and one isolated Undo step; the removed formatting stays carried for the next typed character (`a **bold** c`, cut `bold`, type `x` saves `a **x** c`). Cut removes the selected display text, not whole source lines: copied whole lines carry their block prefixes, but cutting them leaves the first line's empty marker and the following line ending (`> a`, `> b`, `z`, cut `a`…`b`, leaves `> ` then `z`); pasting the copy back replaces that marker. → crates/futo-notes-editor/tests/clipboard.rs
- Paste reads plain text as Markdown and keeps the copied characters: edge spaces, tabs, runs of whitespace and soft-line leading whitespace stay visible, and one trailing copied line ending is dropped (`x ` + newline into `ab|cd` saves `abx cd`). Pasted line endings take the caret line's spelling, so a CRLF note stays CRLF. A paste is one isolated accepted edit and Undo step. → crates/futo-notes-editor/src/session/blocks/clipboard/paste.rs
- A single pasted line that is a block marker alone (`#`, `-`, `>`, `1.`, `- [ ]`), starts with indentation, or opens a fence goes in as its characters, escaped locally at a line start. Inline text and soft lines without blocks or blank lines go through ordinary isolated input, so a replaced selection carries its first format; text wrapped in one style's delimiters inside or beside a span of that style joins it (`**b**` after `**a**` saves `**ab**`). → crates/futo-notes-editor/tests/clipboard.rs
- A pasted block takes its own line inside the caret's quote and list containers: the line splits at the caret, text before and after keeps its own block (a heading tail stays a heading), inline spans cut by the split or by a pasted paragraph break close and reopen (`**ab**` + `x`, blank line, `y` at `a|b` saves `**ax**`, blank line, `**yb**`; a link keeps its destination on both sides), and leading or trailing pasted paragraph lines run on into the caret's text. A list-only paste in a list item adds sibling items, splitting the item mid-line; other blocks nest under the item. A pasted quote replaces the marker of an empty quote line, so cut quote lines paste back without nesting. A blank line separates an ordered list that cannot interrupt the preceding text (also when the caret starts a soft line or a heading line after a paragraph) and a trailing list or quote from following text; an unclosed pasted fence is closed. Paste into fenced or indented code inserts the text verbatim, unescaped, each further line repeating the code line's container and indentation prefix so it stays in the code block. Empty fenced bodies retain that ownership even when the display caret’s source bound is on the hidden closing row. → crates/futo-notes-editor/src/session/blocks/clipboard/paste.rs, crates/futo-notes-editor/tests/clipboard.rs
- Paste work is proportional to the pasted text and the caret's line and affected paragraph window; it does not grow with distant note content. Paste inside a table cell (#310) takes the cell path (see tables.md); rich HTML paste (#303) is deferred. → crates/futo-notes-editor/tests/clipboard.rs
- Store, native FFI and portable WASM expose `copy_markdown`, `cut_markdown` and `paste_markdown`; copying reads the page's draft, so a paused draft stays copyable. Rejected append leaves the draft, selection and history unchanged; checkpoint and reopen reproduce the pasted and cut bytes. → crates/futo-notes-store/src/editor_session/clipboard.rs, crates/futo-notes-store/src/tests/editor_session/clipboard.rs, crates/futo-notes-ffi/src/editor/clipboard.rs, crates/futo-notes-editor/src/portable/clipboard.rs, crates/futo-notes-editor/tests/clipboard/wasm-clipboard-consumer.mjs
