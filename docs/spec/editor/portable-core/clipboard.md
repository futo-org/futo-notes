# Plain Markdown copy, cut and paste

Every line is read alone (linedown.md), so the clipboard writes what was copied and pasted; it never adds a blank line, an entity or an escape because of what the text is.

- Copy exports the exact source of a display selection. A selection starting at a line's display start and reaching that line's end carries the line's quote, list, task and heading markers; one ending at a line's display end carries the closing syntax there. A bold, italic, strikethrough, code or link mark that a selection boundary cuts is closed or opened again with its own spelling (a link keeps its destination), outside edge spaces and tabs; a selection of only spaces and tabs gets no marks. The first copied line's leading whitespace comes off every copied line, so copied nested items keep their nesting relative to the first. CRLF stays as written; code lines copy without their fence lines unless the selection reaches over them. A copied opening fence without its closing fence gains a matching closing fence; a selection starting inside code does not gain one. A collapsed selection copies nothing. → crates/futo-notes-editor/src/engine/commands/clipboard/copy.rs
- Cut returns the copied Markdown and removes the selection exactly as Backspace over it does, as one accepted edit and one Undo step that restores the exact bytes and selection. Like Backspace it always lands. It removes the selected display text, not whole lines: cutting `a`…`b` from `> a`, `> b`, `z` leaves `> ` then `z`, and pasting the copy back there gives `> a`, `> b` again. The formats of the cut text's first character stay carried for the next typed character (`a **bold** c`, cut `bold`, type `x`: `a **x** c`), also after Redo. → crates/futo-notes-editor/src/engine/commands/clipboard/mod.rs
- Paste writes the pasted text as it is: edge spaces, tabs, runs of whitespace, leading whitespace on later lines and Markdown syntax all stay (`-` pasted on an empty line is saved as `-`). One trailing copied line ending is dropped (`x ` plus a line ending into `ab|cd` saves `abx cd`), unless it is all that was pasted, and every pasted `\n` or `\r\n` takes the caret line's line ending (on the note's last line, the one above it), so a CRLF note stays CRLF. A lone `\r` is an ordinary character. Pasting nothing at a caret changes nothing; over a selection it removes it. → crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs
- A paste is one accepted edit and one Undo step of its own; text typed before or after it is a separate step. Pending marked text commits first, in the same acceptance and as its own Undo step. → crates/futo-notes-editor/src/engine/command.rs `Engine::run`
- Outside tables, paste lands as typing does even when it changes how later lines read. A paste on a table line outside its cells uses the command guard; one that would change another table line is cancelled. → crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs
- Text without a line break, other than a block line, lands at the caret as typing it would: inside the marks that start there (a selection of bold text replaced by `*it*` saves `***it***`), in the formats a toolbar toggle left the caret carrying (Bold on, paste `x y`: `**x y**`), with the caret after it. Text that does not show as typed (a link, an image, a wikilink) is written inside the carried formats' house marks instead (Bold on, paste `[x](u)`: `**[x](u)**`; Code on: `` `[x](u)` ``, shown literally), kept only when every pasted visible character then shows in the carried formats plus its own and every other character as before; otherwise it is pasted plain. → crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs, crates/futo-notes-editor/src/engine/edit/plan.rs `plan_input`, crates/futo-notes-editor/src/engine/commands/clipboard/carried.rs
- A pasted link never lands inside another link's text: inside one, that link closes before it and opens again after it (`[ab|cd](u)` with `[x](v)` saves `[ab](u)[x](v)[cd](u)`); at a link's text start or end the pasted link goes before or after it. Other marks stay around it. → crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs `link_split`
- Pasted lines after the first take the caret line's quote markers (`> q|` with `a`, blank, `b` saves `> qa`, `>`, `> b`); they take no list marker and no indent, so plain lines pasted into a list item are plain lines under it. → crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs
- A first pasted line that is a block (heading, list item, quote, divider or fence) starts its own line: after the text before the caret, with the caret line's quote markers (`ab|cd` with `# Title` saves `ab`, `# Title`, `cd`); or, with no text before the caret, in place of the caret line's own marker (an empty bullet, heading or quote line takes the pasted line instead of nesting it). A pasted quote line replaces the caret line's quote markers too, so cut quote lines paste back without nesting. → crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs
- A pasted list takes the caret line's indent on every line, so a list pasted into a list item becomes items beside it and nested pasted items keep their nesting under them (`  - |` with `- x`, `  - y` saves `  - x`, `    - y`). Pasted into an item's text, it splits the item: the text before the caret stays in its item, the pasted items follow, and the text after the caret goes to an item of its own with the caret item's marker as typed (`- ab|cd` with `- x`, `- y` saves `- ab`, `- x`, `- y`, `- cd`). Numbers are written as pasted; nothing is renumbered. → crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs
- Text after the caret joins the last pasted line, unless that line is a block or the paste leaves a fence open: then it keeps a line of its own with the caret line's markers (`## Head|tail` with `# T` saves `## Head`, `# T`, `## tail`). A fence the paste opens and leaves open is closed after the pasted lines, with its own characters at its own indent (`ab|cd` with a fence and `code` saves `ab`, the fence, `code`, a closing fence, `cd`). Inside a quote a pasted fence is quoted text and is not closed. → crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs `shape`
- Marks the caret is inside close at the first pasted line break and open again where the text after the caret continues (`**a|b**` with `x`, `y` saves `**ax**`, `**yb**`; a link keeps its destination on both sides). A caret at a mark's text start pastes before the mark, at its text end after it. → crates/futo-notes-editor/src/engine/commands/marks.rs `split`
- Paste in fenced code inserts the text verbatim, unescaped, and it stays code: when a pasted line would close the fence (a run of the fence's character at least as long), the opening and closing fence lines grow one character longer than the longest such run. An empty code block takes the pasted lines as its code. → crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs `code_paste`
- Paste over a selection that cuts a code block's frame writes what typing over it writes (the frame is kept, fenced-code.md), with the pasted text as it is. → crates/futo-notes-editor/src/engine/edit/plan.rs
- Paste inside one table cell stays in that cell, as the table family writes it (tables.md): edge blank lines go, other line breaks become one space, and a pipe is written `\|` (`| x| |` with `1`, `2` saves `| x1 2 |`). A caret on a table line outside its cells pastes as it would anywhere; a selection across cells or out of the table is refused (`UnrepresentableFormat`, never `InvalidRange`, #355) and changes nothing. Rich HTML paste (#303) is deferred. → crates/futo-notes-editor/src/engine/commands/tables/paste.rs `cell_paste`, crates/futo-notes-editor/src/engine/commands/clipboard/paste.rs
- Paste work is proportional to the pasted text and the lines it lands on; it does not grow with distant note content (200 pasted lines into the middle of a 20,000-line note read 2.5 KB and take about 0.24 ms in a release build). → crates/futo-notes-editor/src/engine/tests/clipboard/rules.rs
- Store, native FFI and portable WASM expose `copy_markdown`, `cut_markdown` and `paste_markdown`; copying reads the page's draft, so a paused draft stays copyable. Rejected append leaves the draft, selection and history unchanged; checkpoint and reopen reproduce the pasted and cut bytes. → crates/futo-notes-store/src/editor_session/clipboard.rs, crates/futo-notes-store/src/tests/editor_session/clipboard.rs, crates/futo-notes-ffi/src/editor/clipboard.rs, crates/futo-notes-editor/src/portable/clipboard.rs, crates/futo-notes-editor/tests/clipboard/wasm-clipboard-consumer.mjs
