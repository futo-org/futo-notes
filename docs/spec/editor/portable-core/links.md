# Link editing and source ownership

These are the portable replacement core's contracts. The shipping Milkdown editor
keeps its existing interaction contract until renderer integration and cutover.

- Link inspection reports the current canonical visible range, destination and optional title; it distinguishes no link from a mixed or partially selected link. A bare `www.` destination uses the parser's `http://` meaning while visible URL text stays verbatim. → crates/futo-notes-editor/src/inline/links.rs, crates/futo-notes-editor/tests/links
- Corrections inside a link preserve its destination, title, unselected text and nested formatting. Setting a destination, inserting a link and unlinking retain exact untouched source, meaningful selection affinity and exact Undo/Redo; references retain their current declaration and remaining uses. → crates/futo-notes-editor/src/session/links.rs, crates/futo-notes-editor/tests/links/reference_blocks.rs
- Ordinary typed bare URLs link at their actual word ending with the extent and destination the canonical parser gives the saved source; Markdown punctuation inside the URI is not independently consumed as formatting. Trailing punctuation remains outside the link. → crates/futo-notes-editor/src/inline/links.rs, crates/futo-notes-editor/tests/links/word_end.rs
- Hand-typed link punctuation remains visible text. A typed `<https://x.test>` keeps one visible angle pair around the URI, and its standard saved spelling reopens with the same visible text and clean inner destination before and after activation. Loaded authored punctuation is interpreted as saved source, not as new typing.
- An unfinished typed WWW angle word can retain its actual input lifetime through continuation, correction, selection movement and history. An explicit input mutation that retires that lifetime does not revive it merely by restoring equal visible text; a loaded or recovered equal source never acquires it. → crates/futo-notes-editor/src/inline/typed_angle, crates/futo-notes-store/src/tests/editor_session/links/input_lifecycle.rs
- A complete committed text input ending in one supported whitespace scalar preserves its literal angle text and canonical inner link; TAB and nonbreaking space follow the same single-ending rule. CRLF or multiple ending whitespace scalars remain literal without an inner link. This text-input contract does not reinterpret raw Markdown clipboard input or provisional marked text as ordered typing. → src/features/editor/milkdown/linkCaseShippingOracle.test.ts
- Inline and fenced Code isolate link interpretation. Removing Code from an actually typed word can retain its original live word-ending behavior; removing Code from loaded or recovered equal source cannot create a typing lifetime. Code deletion and a physical split preserve all required surviving text atoms, Code spans and foreign fields before accepting their standard-source result. → crates/futo-notes-editor/src/inline/guarded_words
- A successful own-action relink applies the canonical identity mapping to the live source and every actual Undo/Redo source generation without adding a user Undo step. Unchanged fields keep their individual lifetimes; a transformed URI that becomes literal retains its exact intended text and formats, including literal pre-Code history, without retaining an invalid link owner. → crates/futo-notes-editor/src/session/relink
- A relink can give an existing incomplete typed WWW seed complete canonical meaning while preserving its original phase; only subsequent actual input performs closer and word-ending activation. It cannot enroll loaded equal text. Complete retained entity and escape atoms outside a rewritten target preserve their exact source and selection identity.
- Reference-dependent edits use the current document's canonical winning declaration, normalized label meaning and title after earlier edits and nested actions. Derived body edits are checked in their actual final physical parent, including hidden container spelling and opaque fences; locally plausible declaration syntax alone does not authorize changing distant reference meaning.
- Every externally returned caret, correction endpoint and history selection resolves in its own actual source generation, including complete decoded atoms and source outside a staged window. Equal visible text or equal byte lengths do not establish source ancestry. Invalid ranges, stale revisions and unavailable required atom correspondence reject before recovery acceptance. → crates/futo-notes-editor/src/session/transaction
- Source, canonical meaning, selection, formatting, transient fields and history are prepared before the one final acceptance callback. Append refusal preserves the accepted state, marked overlay and both existing history stacks; the same intent can resume and retry without an extra history group or recovery record. → crates/futo-notes-store/src/tests/editor_session/links/compound_derived.rs, crates/futo-notes-store/src/tests/editor_session/relink_guarded/literal.rs
- Transient input ownership is in-session state, not saved Markdown or recovery metadata. Saving and reopening preserve standard-source text and canonical meaning and begin with empty Undo/Redo; they never restore a prior live input lifetime. → crates/futo-notes-editor/src/inline/pending_links, crates/futo-notes-store/src/editor_session/recovery.rs
- Ordinary local link work stays in its affected paragraph windows; a genuine canonical declaration/use transition and an explicit own-action history relink can require document-wide work. Parser-input bytes, owned meaning copies and charged metadata/source-correspondence work are reported at their actual owners; these counters do not measure all allocations, Ropey internals, semantic caret diff CPU or physical latency. → crates/futo-notes-editor/src/types.rs, crates/futo-notes-editor/src/inline/links/bare.rs, crates/futo-notes-editor/src/inline/query_growth_tests.rs
