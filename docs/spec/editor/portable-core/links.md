# Link editing

A link is `[text](destination)` on one line
([linedown.md](linedown.md)). The cases are `crates/futo-notes-editor/tests/fixtures/engine/links.json`.

- Inspecting a link reports the text range, destination and title of the link or web address the selection lies in; a caret at its edge takes the side its affinity names, and a selection that reaches outside it, or touches no link, reports none. → crates/futo-notes-editor/src/engine/commands/inline/links/mod.rs `link_at`
- A bare URL links over GFM's extent, with trailing punctuation left outside; `www.example.com` keeps its text and has the destination `http://www.example.com`. `<https://x.test>` shows as the address without its angle brackets. → crates/futo-notes-editor/src/lines/url.rs
- Inside inline code or a code block nothing reads as a link, and link commands skip code lines. → crates/futo-notes-editor/src/lines/inline/mod.rs
- A link never crosses a line. Linking a selection writes one link per line, and per table cell, around the text selected there, with spaces at its ends left outside. A `|` line that is not in a table is a plain line, linked whole like any other. → crates/futo-notes-editor/src/engine/commands/inline/links/write.rs `link_selection`
- Linking text that covers part of another link, a web address, inline code, a wikilink, an image or a tag covers that piece whole; links inside the selection come off first, since links do not nest. A format crossing the selection's edge closes before the link and reopens inside it, so every character keeps its formats (`**ab⟦c**d⟧` becomes `**ab**[**c**d](u)`). → crates/futo-notes-editor/src/engine/commands/inline/links/mod.rs `link_run`
- A destination is written as given when it reads back as itself, else inside `<…>`, else with a `\` before each character that would end it; the line is read back to choose. In a table cell a destination's `|` is written `\|`, so it never ends the cell; outside a table it is written as given. → crates/futo-notes-editor/src/engine/commands/inline/links/mod.rs `spellings`, crates/futo-notes-editor/tests/fixtures/engine/links.json
- A new destination on a link changes only the destination: the text, a title and the source around it stay as they were. A web address given a destination becomes `[address](destination)`. → crates/futo-notes-editor/src/engine/commands/inline/links/mod.rs `link_command`
- An empty destination removes a link and keeps its text and that text's formats. Over a selection that covers more than one link or reaches outside one, it removes every link whose text the selection touches, on each line and in each table cell. A web address has no link syntax to remove and stays as it is. → crates/futo-notes-editor/src/engine/commands/inline/links/mod.rs `link_command`, `unlink_selection`
- With the caret outside any link, a destination is inserted at the caret: as the address itself when that reads as a web address with the same destination, else as `[destination](destination)`; the caret ends after it. → crates/futo-notes-editor/src/engine/commands/inline/links/mod.rs `insert_link`
- Editing a link with new text writes `[text](destination)` in place of the link (keeping its title) or of the selection, and puts the caret after the text. The text is written as typed, so Markdown in it reads as Markdown. Text that cannot be a link's text on one line (an unmatched `]`, or a pipe inside a table cell) or that holds a line break or NUL is refused with `InvalidText`. Unchanged text sets only the destination; empty text removes the link and its text; an empty destination leaves the text plain; empty text at a caret outside a link does nothing. → crates/futo-notes-editor/src/engine/commands/inline/links/mod.rs `relabel`
- Each link command is one host acceptance and one Undo step that restores the exact bytes and selection; when the text does not change, the selection stays where it was. Marked text commits first, as its own Undo step. A stale revision, an invalid range, a destination holding CR, LF or NUL, or a refused acceptance changes nothing and keeps the marked text. → crates/futo-notes-editor/src/engine/command.rs `run`
- A link command reads only the lines it changes, a few times each to choose a spelling, and counts those reads as parser input. → crates/futo-notes-editor/src/engine/commands/inline/links/mod.rs
- The engine decides what a link destination means, so every shell agrees. When a destination is saved from the link prompt, a destination that names an existing note (resolved as a tap would, from the current note) stays a note link; otherwise a web-looking address gets https://: a typed address with no scheme that looks like a web address (it starts with `www.`, or ends in a well-known public domain, and does not end in `.md`) is written with `https://`; a file-like name such as `setup.sh`, `main.rs` or `my.notes`, a note path and anything unclear stay exactly as typed. When a link is tapped, only an explicit scheme (`http`, `https`, `mailto`, `tel`, `sms`) is external; `javascript:`, `file:`, `data:` and every other scheme never open. A destination with no scheme is a note path, resolved from the current note's folder (a leading `/` starts at the vault root, `.md` is optional, `#fragment` and `?query` are ignored): the note opens when it exists and otherwise the tap does nothing. → crates/futo-notes-editor/src/link_target.rs, crates/futo-notes-editor/tests/link_target.rs, crates/futo-notes-ffi/src/editor/links.rs
- An adopted own-action relink takes its bytes from the store's canonical text-level wikilink rewrite and is one ordinary isolated edit and Undo step ([saving](recovery.md)). Transient input lifetimes inside its changed window end; it never creates one. → crates/futo-notes-editor/src/engine/commands/wikilinks/relink.rs
