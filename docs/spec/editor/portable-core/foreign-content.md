# Front matter and unfamiliar Markdown

- Front matter is the dialect's: line 1 exactly `---` and a later line exactly `---`, with the lines between them as its body (linedown.md, "Front matter"). Without the closing line, line 1 is a divider and every line reads as usual; `--- `, a byte-order mark before `---`, `+++`, an indented or mid-note `---` are not front matter. → crates/futo-notes-editor/src/lines/block.rs, crates/futo-notes-editor/tests/fixtures/linedown/
- Front matter is inert metadata: its fence lines are hidden, each body line shows its whole text with no inline or block meaning, and its block descriptions set `metadata`. Front matter closed on the note's last line shows one empty line for the body. Blank lines, fence spacing and line-ending bytes stay exact. → crates/futo-notes-editor/src/engine/line.rs, crates/futo-notes-editor/tests/foreign.rs
- The caret opens at the body start and never rests in front matter, also after an edit lands there. A selection covering all of the front matter deletes it with its fences; input never changes part of it. Outside changes (sync, another program) may rewrite it. → crates/futo-notes-editor/src/engine/mod.rs `metadata_end`, crates/futo-notes-editor/src/engine/tests/mod.rs `front_matter_is_metadata_and_the_caret_starts_in_the_body`
- An edit that can open or close front matter (on line 1, or on a `---` line below it) re-reads from line 1; any other edit re-reads only its lines and on until the carry settles. → crates/futo-notes-editor/src/engine/read.rs
- There is no raw HTML, footnote or reference definition: `<div>`, `<!-- -->`, `[^1]` and `[id]: url` lines are plain text, shown and saved exactly as written, and Markdown on them reads as on any line. → docs/spec/editor/portable-core/linedown.md, crates/futo-notes-editor/tests/foreign.rs
- Malformed text (unclosed fences, emphasis or links, a lone CR, NUL) opens with its exact source, a display and an editable caret; opening and saving without an edit changes no bytes. → crates/futo-notes-editor/src/engine/tests/properties/
- Rust, WebAssembly and native FFI block descriptions all carry `metadata`, so hosts can render front matter as a panel. → crates/futo-notes-ffi/src/editor/contract.rs
