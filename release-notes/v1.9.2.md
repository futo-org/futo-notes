# v1.9.2

A bug-fix release, mostly for the editor and syncing.

Fixes

- Typing a title right after opening a new note no longer drops its first letters.
- Sync no longer keeps a live connection running after you switch away from the app.
- Sync does its network work in the background, so the app stays responsive while it syncs.
- Pasting plain text keeps its line breaks and spacing. Pasting a table with only a header row, or a block of text into a heading, list item or table cell, now lands where you expect.
- Typed formatting follows Markdown's rules more closely. A backslash-escaped symbol stays as text, URLs keep their underscores and asterisks, and seven # signs no longer make a heading.
- Select all followed by Code block or Bullet list keeps every line.
- Pressing Enter at the start of a quote keeps the empty line it makes. Splitting a checked task starts the new item unchecked.
- Keyboard shortcuts held with Shift while Caps Lock is on no longer run the shortcut without Shift, such as undoing when you meant to redo.
- Moving the cursor around a note with front matter no longer gets stuck above it.
- Find and [[ link suggestions now match Greek words ending in sigma.

## Short

Taking a photo in a note no longer crashes. The app now asks for camera access first. Fixed sync over HTTPS to servers with public certificates. Fixed the keyboard closing at the start of a task item. Plus many editor fixes for pasting, typed formatting and Select all, and a fix for dropped letters when titling a new note.
