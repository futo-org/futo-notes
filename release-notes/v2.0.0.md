# v2.0.0

FUTO Notes 2.0 has a new editor. It's the biggest change we've made to the app so far.

We rewrote the notes engine from the ground up to be more performant, consistent, and native. On iPhone, your editor is no longer a webview - it uses the native text engine provided by Apple. For you, this means a much smoother experience when doing text selection, changing markdown types, and opening/closing notes.

Sync

- If a note changes on another device while you're editing it, FUTO Notes merges the two. Only when both sides changed the same words does it make a conflict copy.
- Renaming or moving a note reaches your other devices as a rename, even offline.
- If another device deletes a note you have unsaved edits in, your edits are kept.

Also in 2.0

- Delete a folder with or without its notes.
- Moving or renaming a folder whose notes link to each other is much faster.
- A #tag inside code no longer counts as a tag.

We'd love to hear how the new editor feels. Settings → Send feedback reaches us directly.
